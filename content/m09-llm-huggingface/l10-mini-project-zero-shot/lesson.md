## Зачем это нужно

В соревновании 2 нужно разложить по классам картинки, ответов для которых нет ни у кого: их знает только проверяющий сервер. Чтобы прийти туда с хорошим решением и честной оценкой, проделаем весь путь на открытой половине картинок:

- поделим её на две части: на `dev` выбираем настройки, на `test` один раз проверяем выбор;
- соберём классификатор из приёмов уроков 9.7–9.8;
- разберём ошибки и научимся откладывать сомнительные ответы;
- напишем функцию, которая выдаёт ответы в формате соревнования.

Новых понятий нет.
