## Зачем это нужно

Zero-shot работает, когда классы можно назвать понятными модели словами. Но часто задача другая: «срочная заявка или нет», «категория объявления по внутреннему справочнику» (пример из ноутбука курса). Названия таких классов модели ничего не скажут.

**Перенос обучения** (transfer learning) — взять модель, которая уже научилась общим вещам на огромных данных, и приспособить её к своей задаче по небольшой разметке. Есть два способа:

- **признаки**: модель не трогаем, берём её векторы как признаки и учим поверх простую модель — например, логистическую регрессию. Такой подход называют линейным зондом;
- **дообучение** (fine-tuning): продолжаем обучать саму сеть с новой головой на своих примерах.

## Векторы как признаки

Научим логистическую регрессию узнавать группу картинки — Animalia, Dishes или Other — по 512 числам CLIP:

```python
y = images['group'].to_numpy()
big = images['group'].isin(['Animalia', 'Dishes', 'Other']).to_numpy()
train_g, test_g = dev & big, test & big
probe = LogisticRegression(max_iter=1000).fit(X[train_g], y[train_g])
pred = probe.predict(X[test_g])
print('Обучающих картинок:', train_g.sum(), '| доля верных на test:', (pred == y[test_g]).mean().round(3))
print('Ошибки:', images.loc[test_g].loc[pred != y[test_g], 'class'].tolist())
```

Логистическая регрессия училась на 343 картинках и узнала группу 343 новых в 96 % случаев. CLIP ничего не знает о наших группах, но его векторы уже разделяют животных, еду и предметы. Регрессии осталось провести между ними границы.

Посмотрите на ошибки: ibis, emu, beaver, okapi, rhino… Все 14 картинок из группы Other модель отнесла к Animalia — и это животные! Группа Other собрана из другого набора картинок (похоже, Caltech-101), где животные тоже есть, только с английскими названиями. Модель права насчёт того, что на картинке, а группа говорит о том, откуда класс взят. Прежде чем винить модель, посмотрите на её ошибки.

## Сколько нужно примеров

```python
def probe_acc(k, seed):
    rng = np.random.default_rng(seed)
    idx = np.where(train_g)[0]
    pick = np.concatenate([rng.choice(idx[y[idx] == g], size=k, replace=False)   # k картинок каждой группы
                           for g in ['Animalia', 'Dishes', 'Other']])
    model = LogisticRegression(max_iter=1000).fit(X[pick], y[pick])
    return (model.predict(X[test_g]) == y[test_g]).mean()

for k in [2, 5, 10, 20, 50]:
    print(f'{k:2} картинок на группу: {np.mean([probe_acc(k, s) for s in range(5)]):.3f}')
```

По две картинки на группу — всего шесть размеченных примеров — и уже 87 % верных. С пятьюдесятью — 93 %. Главную работу сделали признаки, выученные CLIP на сотнях миллионов картинок. Поэтому перенос обучения и нужен: размечать приходится в сотни раз меньше, чем для обучения с нуля.

## Пример или название?

Вернёмся к 349 классам. Вместо названий возьмём для каждого класса **прототип** — вектор его картинки из `dev` — и будем искать ближайший прототип, как ближайшую подпись в уроке 9.8:

```python
with np.load('zs_prompts.npz') as data:
    prompts = pd.DataFrame({k: [str(x) for x in data[k]] for k in ['class', 'group', 'language', 'variant']})
    prompt_emb = data['emb'].astype(np.float32)
raw = prompts[prompts['variant'] == 'raw']
classes = raw['class'].to_numpy()
allowed = ((images['group'].to_numpy()[:, None] == raw['group'].to_numpy()[None, :]) &
           (images['language'].to_numpy()[:, None] == raw['language'].to_numpy()[None, :]))
proto = np.zeros((len(classes), X.shape[1]), dtype=np.float32)
for j, c in enumerate(classes):
    v = X[dev & (images['class'] == c).to_numpy()].mean(axis=0)
    proto[j] = v / np.linalg.norm(v)
names = prompt_emb[(prompts['variant'] == 'photo_group').to_numpy()]
for title, E in [('одна картинка на класс', proto), ('название класса', names)]:
    pred = classes[np.where(allowed, X @ E.T, -np.inf).argmax(axis=1)]
    print(f'{title:22} {(pred == images["class"].to_numpy())[test].mean():.3f}')
```

Одна фотография на класс даёт 0,56, а название — 0,87. На фотографии кроме самого объекта есть фон, ракурс и случайные детали, а название описывает класс точно. Авторы CLIP получили похожий результат: zero-shot в среднем не уступает логистической регрессии, обученной на четырёх примерах каждого класса. Но с десятками примеров на класс обучение уже обгоняет названия.

## Дообучение трансформера

Второй способ — дообучить саму модель. Так из `distilbert-base-uncased` получилась модель тональности из урока 9.4: её дообучили на 67 тысячах предложений набора SST-2. В ноутбуке курса есть пример для классификации объявлений по трём категориям. Он требует видеокарты и запускается в Colab:

```python norun
from datasets import load_dataset
from transformers import AutoTokenizer, AutoModelForSequenceClassification, Trainer, TrainingArguments

model_name = 'distilbert-base-uncased'
dataset = load_dataset('csv', data_files='ads.csv')            # столбцы text и label

tokenizer = AutoTokenizer.from_pretrained(model_name)
def tokenize(batch):
    return tokenizer(batch['text'], truncation=True, padding=True)
dataset = dataset.map(tokenize, batched=True)                  # токенизация всех текстов

model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=3)   # новая голова на 3 класса
args = TrainingArguments(output_dir='./results', per_device_train_batch_size=8, num_train_epochs=3)
trainer = Trainer(model=model, args=args, train_dataset=dataset['train'])
trainer.train()
```

Шаги знакомы по модулю 8. Модель получает новую голову на три класса со случайными весами. Предупреждение «Some weights … newly initialized» из урока 9.4 здесь ожидаемо: голову и предстоит обучить. Дальше — несколько эпох с маленьким шагом обучения: по умолчанию 0,00005. С большим шагом сеть быстро «забудет», чему научилась на огромных данных. И, как всегда, нужны validation и test (модули 5–6): Trainer умеет считать качество на отложенной части.

| Подход | Размеченных примеров | Что нужно |
|---|---|---|
| Zero-shot | ни одного | понятные модели названия классов |
| Признаки + простая модель | десятки | векторы модели, обычный компьютер, минуты |
| Дообучение | сотни и тысячи | видеокарта, часы |

## Типичные ошибки

:::mistake Проверять зонд на тех же примерах, на которых учили
Даже маленькая модель на 512 признаках легко запоминает обучающие картинки. Качество считают на отложенных данных — здесь это `test`.
:::

:::mistake Дообучать с большим шагом обучения
Сеть «забудет» то, чему научилась при предобучении, и превратится в модель, обученную на одной вашей маленькой выборке. Шаг дообучения в десятки раз меньше обычного.
:::

:::mistake Считать каждую ошибку зонда ошибкой модели
14 «ошибок» в группах — животные, записанные в группу Other. Иногда неправа разметка или сама постановка задачи.
:::

## Что запомнить

- Перенос обучения — готовая модель плюс небольшая разметка для своей задачи. Два способа: признаки модели + простая модель или дообучение самой сети.
- Векторы CLIP — сильные признаки: логистической регрессии хватает нескольких примеров на класс.
- Названия классов в zero-shot стоят нескольких размеченных примеров. С десятками примеров на класс обучение выигрывает.
- Дообучение (Trainer) — новая голова, несколько эпох, маленький шаг, видеокарта и, как всегда, отложенные данные для проверки.
