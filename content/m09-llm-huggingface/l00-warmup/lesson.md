## Зачем это нужно

Модуль 9 — про модели, которые «читают» тексты и «смотрят» на картинки. Внутри у них всё те же числа:

- текст режут на слова и считают — так устроена простейшая языковая модель (урок 9.1);
- слова и картинки превращают в векторы, а похожесть векторов измеряют скалярным произведением (уроки 9.2 и 9.7);
- на выходе классификатор выдаёт вероятности — как логистическая регрессия и сеть из урока 8.7;
- качество модели проверяют по группам: в какой теме отзывов она ошибается чаще (урок 9.4).

Данные для разминки — сам этот курс: файл `course_texts.txt` содержит связный текст уроков модулей 0–8, по абзацу на строку, без кода и формул.

## Слова — в числа

```python
words = re.findall(r'[а-яё]+', text.lower())     # все русские слова подряд
counts = pd.Series(words).value_counts()
print('Слов в корпусе:', len(words), '| разных:', counts.size)
print(counts.head(10))
print('Слов, встретившихся один раз:', (counts == 1).sum())
```

`re.findall(шаблон, текст)` возвращает все куски текста, подходящие под шаблон. `[а-яё]+` — подряд идущие русские буквы, то есть слова. В текстах курса 41 737 слов, из них 6 611 разных. Чаще всего встречаются служебные слова — «и», «в», «на». А почти половина разных слов (3 209) встретилась всего один раз. Это свойство любого языка: несколько слов очень частые, огромное множество — редкие. В уроке 9.1 оно станет главной трудностью простой языковой модели.

## Статистика по группам

В уроке 9.4 модель будет оценивать тональность коротких отзывов. Таблица уже готова:

```python
reviews = pd.read_csv('reviews.csv')
print(reviews.head(3))
print(reviews['domain'].value_counts())
print('Доля положительных по темам:')
print(reviews.groupby('domain')['label'].mean().round(2))
```

В таблице 88 отзывов: текст `text`, класс `label` (1 — положительный, 0 — отрицательный), тема `domain` и язык `lang`. `groupby('domain')['label'].mean()` — доля положительных отзывов в каждой теме: среднее нулей и единиц равно доле единиц (урок 3.2). Почти во всех темах положительных ровно половина. Исключение — «tricky»: там собраны хитрые отзывы с отрицаниями и сарказмом. По тем же группам в уроке 9.4 посчитаем, где модель ошибается чаще всего.

## Векторы и скалярное произведение

```python
a = np.array([3.0, 4.0])
b = np.array([4.0, 3.0])
print('Скалярное произведение a @ b =', a @ b)              # 3·4 + 4·3
print('Длина a =', np.sqrt(a @ a))                           # √(3² + 4²)
unit = a / np.sqrt(a @ a)                                    # вектор длины 1 того же направления
print('Нормированный a:', unit, '— его длина', np.sqrt(unit @ unit))
```

Скалярное произведение `a @ b` — сумма попарных произведений (как взвешенная сумма нейрона, урок 8.1). Длина вектора — корень из его скалярного произведения на себя. Разделив вектор на длину, получаем вектор длины 1 с тем же направлением. Скоро слова и картинки станут векторами из сотен чисел, а их «похожесть» будет считаться именно так.

## Вероятность класса и порог

```python
z = np.array([2.3, -1.1, 0.4, -3.0, 4.2, -0.2, 1.5, -2.2])   # оценки модели для 8 отзывов
y = np.array([1, 0, 0, 0, 1, 1, 1, 0])                         # настоящие классы
p = 1 / (1 + np.exp(-z))                                       # сигмоида → вероятность класса 1
pred = (p >= 0.5).astype(int)
print('Вероятности:', p.round(3))
print('Прогноз:', pred, '| доля верных:', (pred == y).mean())
```

Сигмоида переводит оценку модели в вероятность класса 1, порог 0,5 — в класс (урок 8.7). Модель тональности в уроке 9.6 устроена так же, только классов два и для них — две оценки, а вместо сигмоиды — её обобщение, softmax.
