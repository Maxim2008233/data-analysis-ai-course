## Зачем это нужно

Чтобы обучить трансформер вроде DistilBERT с нуля, нужны миллиарды слов и недели работы видеокарт. Но обученные модели выкладывают в открытый доступ. **Hugging Face Hub** (huggingface.co) — хранилище, где лежит больше миллиона готовых моделей для текста, картинок и звука. У каждой модели есть страница-карточка: для какой задачи она обучена, на каких данных и для какого языка.

Библиотека **transformers** скачивает модель по имени и запускает её. Функция **pipeline** делает это одной строкой — без обучения и почти без кода.

## Pipeline: модель одной строкой

```python
from transformers import pipeline

classifier = pipeline('sentiment-analysis', model='distilbert-base-uncased-finetuned-sst-2-english')
print(classifier(["I've been ready for a HuggingFace course my whole life.", 'I hate this so much!']))
```

`pipeline(задача, model=имя)` создаёт готовый классификатор. Ответ — список словарей: метка `label` и уверенность модели `score`. Первая фраза положительная с уверенностью 0,990, вторая — отрицательная с уверенностью 0,999. Ровно такие числа получились в ноутбуке курса.

Внутри pipeline три шага:

1. **Токенизатор** режет текст на токены и заменяет их номерами (урок 9.5).
2. **Модель** — трансформер DistilBERT — выдаёт по одной оценке на каждый класс (урок 9.6).
3. **Постобработка**: softmax превращает оценки в вероятности, метка — класс с наибольшей вероятностью.

Имя модели рассказывает, что это за модель. `distilbert` — уменьшенный BERT из урока 9.3, `base` — его размер, `uncased` — модель не различает заглавные и строчные буквы. `finetuned-sst-2-english` — модель дообучили на SST-2, наборе английских отзывов о фильмах.

:::info Как это работает в браузере
Настоящая библиотека transformers работает на PyTorch, а его в браузере нет. Поэтому здесь — учебная версия с тем же интерфейсом. Токенизатор в ней настоящий и работает на любом тексте. Результаты модели для 88 отзывов урока один раз посчитаны настоящей библиотекой и совпадают с Colab до пятого знака. Другие тексты, модели и задачи запускайте в [ноутбуке курса в Colab](https://colab.research.google.com/github/MVRonkin/BasicDataAnalysisCourse/blob/main/Workshops/09_HF_intro.ipynb).

## Все отзывы сразу

В файле урока 88 коротких отзывов с правильными ответами (урок 9.0). Pipeline принимает список текстов:

```python
reviews = pd.read_csv('reviews.csv')
preds = classifier(list(reviews['text']))                 # список из 88 словарей
reviews['pred'] = [1 if p['label'] == 'POSITIVE' else 0 for p in preds]
reviews['score'] = [p['score'] for p in preds]
reviews['correct'] = reviews['pred'] == reviews['label']
print('Доля верных:', reviews['correct'].mean().round(3))
print(reviews.groupby('domain')['correct'].mean().round(2))
```

Модель ни разу не видела наших отзывов и угадала 82 из 88 — 93 %, без всякого обучения. Но средняя доля скрывает различия. В отзывах о еде, отелях и фильмах ошибок нет, а среди «хитрых» отзывов с отрицаниями и сарказмом и среди русских — по две ошибки. Поэтому модель проверяют не только в среднем, но и по группам.

## Уверенные ошибки

```python
wrong = reviews[~reviews['correct']].sort_values('score', ascending=False)
for text, score in zip(wrong['text'], wrong['score']):
    print(f'{score:.3f}  {text}')
```

Четыре ошибки из шести модель сделала с уверенностью выше 0,9. «The service could not have been better» («лучше и быть не могло») она сочла отрицательным отзывом — видимо, её сбило отрицание «not». А в сарказме «Oh wonderful, the app deleted all my photos» она поверила слову «wonderful». Уверенность модели — не вероятность того, что ответ верен.

## Когда модель сомневается

Ответы с низкой уверенностью можно не принимать автоматически, а отдать человеку:

```python
for t in [0.9, 0.99]:
    sure = reviews['score'] >= t
    print(f'Порог {t}: отвечаем на {sure.mean():.0%} отзывов, среди них верных {reviews.loc[sure, "correct"].mean():.1%}')
print(reviews.loc[reviews['lang'] == 'ru', ['text', 'pred', 'score']])
```

С порогом 0,9 модель берётся за 90 % отзывов и ошибается в 5 % из них, остальные 10 % проверит человек. На русских отзывах у шести из восьми уверенность от 0,51 до 0,64: английская модель не понимает языка и почти угадывает. Шесть верных ответов из восьми здесь — скорее удача. Из двух уверенных ответов один ошибочный: «Еда холодная, официант грубый» модель сочла положительным отзывом с уверенностью 0,94.

## Другие задачи и модели

Pipeline умеет не только оценивать тональность. Задачи `'question-answering'` (ответ на вопрос по тексту), `'text-generation'` (продолжение текста), `'summarization'` (краткий пересказ), `'zero-shot-image-classification'` (урок 9.7) и десятки других. В браузере работают только тональность и zero-shot классификация картинок — остальное выдаёт ошибку со ссылкой на Colab:

```python expect-error
pipeline('question-answering')
```

Вот что эти задачи вернули в ноутбуке курса с настоящей библиотекой:

```python norun
qa = pipeline('question-answering')          # модель по умолчанию — distilbert-base-cased-distilled-squad
qa(question='Когда родился Альберт Эйнштейн?', context='Альберт Эйнштейн родился в Германии в 1879 году.')
# {'score': 0.677, 'start': 38, 'end': 42, 'answer': '1879'}

generator = pipeline('text-generation', model='gpt2')
generator('Искусственный интеллект — это', max_length=50)
# [{'generated_text': 'Искусственный интеллект — этои поконманичек (@Pelaz'}]

classifier_ru = pipeline('text-classification', model='DeepPavlov/distilrubert-small-cased-conversational')
classifier_ru('Эта игра просто великолепна!')
# Some weights of DistilBertForSequenceClassification were not initialized ... You should probably TRAIN this model
# [{'label': 'LABEL_0', 'score': 0.5004}]
```

Модель вопросов и ответов нашла в тексте число 1879: ответ — кусок контекста, `start` и `end` — номера его символов. Английская модель справилась с русским текстом, потому что ответ — число. GPT-2 обучали на английских текстах, и русское продолжение вышло бессмыслицей. А русская модель DeepPavlov — просто кодировщик: «головы» для классификации у неё нет. Библиотека создала эту голову со случайными весами и предупредила об этом. Ответ «LABEL_0 с уверенностью 0,50» — подбрасывание монетки. Прежде чем брать модель с Hub, читайте её карточку: для какой задачи, на каких данных и для какого языка её обучали.

## Типичные ошибки

:::mistake Не указывать модель
`pipeline('sentiment-analysis')` без `model=` берёт модель по умолчанию и предупреждает: «No model was supplied, defaulted to…». В новой версии библиотеки модель по умолчанию может смениться. Указывайте модель явно.
:::

:::mistake Применять модель не к тому языку или задаче
Английская модель тональности на русских отзывах почти угадывает, GPT-2 пишет по-русски бессмыслицу. Модель работает на таких данных, на каких её обучали, — это написано в карточке.
:::

:::mistake Считать score вероятностью правильного ответа
`score` — уверенность модели. Четыре из шести ошибок модель сделала с уверенностью выше 0,9. Проверяйте модель на своих размеченных данных.
:::

:::mistake Довольствоваться средней точностью
93 % в среднем, но ошибки сосредоточены в «хитрых», русских, товарных и сервисных отзывах. Смотрите на качество по группам: по темам, языкам, длине текста.
:::

## Что запомнить

- Hugging Face Hub — больше миллиона готовых моделей, у каждой есть карточка. Библиотека transformers загружает модель по имени.
- `pipeline(задача, model=имя)` = токенизатор → модель → постобработка. Ответ — метка и уверенность `score`.
- Модель проверяют на своих размеченных данных и по группам: 93 % в среднем, но ошибки сосредоточены в отдельных темах и языках.
- `score` — уверенность модели, а не гарантия: бывают уверенные ошибки. Сомнительные ответы ниже порога можно отдать человеку.
- Модель работает для той задачи, языка и данных, на которых её обучали.
