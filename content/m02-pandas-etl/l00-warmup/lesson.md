## Зачем это нужно

В этом модуле таблица автомобилей станет объектом pandas — `DataFrame`, а каждая её колонка — объектом `Series`. Хорошая новость: колонка `Series` ведёт себя почти как массив NumPy из модуля 1. Сравнение даёт маску из `True`/`False`, условия объединяются через `&`, `|`, `~`, пропуски обозначаются `NaN`.

А чтобы перекодировать категории («True → Automatic») и создавать новые признаки по правилам, понадобятся словари и функции с ветками `if` из модуля 0. Пять коротких задач освежат всё это до начала работы с таблицами.

## Маски и доли

Сравнение массива с числом даёт маску. Её сумма — **количество** подходящих записей, среднее — их **доля**. Несколько условий объединяют `&` («и»), `|` («или»), `~` («не»); каждое условие — в скобках.

```python
cheap = price < 3000
print('Дешевле 3000 евро:', cheap.sum(), 'объявлений, доля', round(cheap.mean(), 3))

old_long = (year < 2000) & (distance > 300_000)
print('Выпуск до 2000 года и пробег больше 300 тыс. км:', old_long.sum())
```

## Пропуски

`NaN` не равен ничему, даже самому себе, поэтому пропуски ищут функцией `np.isnan`. Обычная медиана с пропуском даёт `nan`, поэтому её считают по известным значениям:

```python
missing = np.isnan(engine)
print('Пропусков в объёме двигателя:', missing.sum())
print('np.median со всеми значениями:', np.median(engine))
print('Медиана известных значений:  ', np.median(engine[~missing]))
```

## Словари и функции с ветками

Словарь переводит одно значение в другое. Метод `.get(ключ, запасное)` не падает с ошибкой, если ключа нет, а возвращает запасное значение. Функция с ветками `if` превращает число в категорию; границы категорий важно проверять отдельно:

```python
fuel_ru = {'Petrol': 'бензин', 'Diesel': 'дизель'}
print(fuel_ru['Diesel'], '|', fuel_ru.get('Electric', 'нет в словаре'))

def price_level(p):
    if p < 5000:
        return 'низкая'
    if p <= 15000:
        return 'средняя'
    return 'высокая'

for p in [4999, 5000, 15000, 15001]:
    print(p, '→', price_level(p))
```

Цена 5000 попала в «среднюю», потому что первое условие строгое (`<`), а 15 000 — тоже в «среднюю», потому что второе условие нестрогое (`<=`). Именно так выглядят правила, которые мы будем применять к целой колонке в уроке 2.9.
