## Зачем это нужно

В уроках 2.6–2.11 обработка шла по шагам, ячейка за ячейкой. Для учёбы это удобно, но в работе аналитика так не делают: если завтра придёт новая выгрузка объявлений, пройти все ячейки заново вручную — долго и рискованно. Поэтому обработку собирают в **функции**: на вход — исходная таблица, на выход — подготовленная таблица и журнал.

Хорошая функция подготовки:

- **не меняет** исходную таблицу — работает с копией;
- **не содержит вписанных чисел**, кроме явно названных констант-границ;
- даёт **одинаковый результат** при повторном запуске;
- работает на **любой части данных** — проверка заданий запустит ваши функции на другой выборке объявлений.

Новых понятий здесь нет. Каждое задание опирается на один–три навыка модуля, рядом есть карточки «Вспомним», а готовые функции предыдущих шагов уже лежат в подготовке задания — так каждый шаг можно выполнить отдельно.

## План проекта

1. **Очистка строк** — функция `clean_rows`: точные повторы, неполные записи, учебная область анализа (уроки 2.6–2.7).
2. **Признаки** — функция `add_features`: исходная метка строки и новый индекс, короткие имена колонок, `Age` и `km_year` (уроки 2.7–2.8).
3. **Категории** — функция `add_categories`: `Transmission`, `km_year_cat`, редкие марки в `Rare` (уроки 2.9–2.10).
4. **Сборка и сохранение** — функция `prepare_cars`: все шаги вместе, журнал обработки и файл `cars_processed.csv` (урок 2.11).
5. **Отчёт аналитика** — какие выводы о подготовленных данных корректны.

Перед заданиями вспомните, как выглядит исходная таблица и чем она «грязная»:

Итог проекта — таблица из 32 067 строк и 15 колонок: ровно такой файл `cars_processed.csv` использует модуль 3.

Почему функция должна работать с копией? Таблица передаётся в функцию «по ссылке»: если функция меняет её на месте, меняется и таблица того, кто функцию вызвал:

```python
def bad_clean(table):
    table.dropna(inplace=True)      # меняет переданную таблицу!
    return table

sample = raw.head(1000).copy()
n_before = len(sample)
bad_clean(sample)
print('Строк в sample до вызова:', n_before, '| после вызова:', len(sample))
```

Поэтому первая строка каждой функции проекта — `table = table.copy()`, а дальше — только присваивания вида `table = table.dropna()`.
