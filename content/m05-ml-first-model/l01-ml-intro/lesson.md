## Зачем это нужно

Сервису нужна оценка цены автомобиля: продавец вводит характеристики — сайт подсказывает разумную цену. Можно ли написать такие правила вручную? Сотни марок и моделей, годы, пробег, объём двигателя — правил понадобились бы тысячи, и они устаревали бы вместе с рынком. **Машинное обучение** решает задачу иначе: правила не пишут, а **находят по примерам** — по 32 тысячам объявлений, где цена уже известна.

> «Машинное обучение — область знаний, которая даёт компьютерам возможность обучаться без непосредственного программирования» — так описал её Артур Сэмюэл в 1959 году.

## Программирование и обучение

| | Программирование | Машинное обучение |
|---|---|---|
| Что задаёт человек | правила: «если…, то…» | примеры: входы и правильные ответы |
| Что получается | программа, точно выполняющая правила | модель, которая сама нашла закономерность |
| Пример | рассчитать налог по ставке | оценить цену машины, распознать лицо |
| Беспилотный автомобиль | описать действия во всех ситуациях | учиться на записях вождения людей |

Мы уже делали шаг к обучению в уроке 3.7: цена «как у похожих машин» — медиана группы. Правило «брать медиану той же марки и года» придумал человек, но **числа** для каждой группы взялись из данных.

## Объект, признаки, ответ

Задачу машинного обучения записывают так: есть **объект** — автомобиль, — описанный **признаками** $x = (x_1, x_2, \dots, x_n)$: годом, пробегом, объёмом двигателя. Есть **целевая переменная** $y$ — цена. Нужно найти функцию $f$, чтобы

$$
\hat{y} = f(x) \approx y
$$

и не только на известных примерах, но и на **новых** машинах, цены которых модель не видела. $\hat y$ («игрек с крышкой») — оценка, прогноз.

![Схема обучения с учителем](ml-scheme.svg "Обучение: пары (x, y) → алгоритм → модель; прогноз: новый x → ŷ")

```python
features = ['Year', 'Distance', 'Engine', 'km_year']
X = df[features]
y = df['Price']
print('Объектов:', X.shape[0], '| признаков:', X.shape[1])
print('Первый объект как вектор признаков:', X.iloc[0].tolist(), '→ ответ', y.iloc[0])
```

Каждая строка `X` — вектор признаков одного объекта, соответствующее значение `y` — его правильный ответ. Обучающие данные — это пары $(x_i, y_i)$.

## Какие бывают задачи

**По тому, есть ли ответы в данных:**

- **обучение с учителем** — в данных есть правильные ответы (цены, классы), модель учится их предсказывать;
- **обучение без учителя** — ответов нет, модель ищет структуру сама: группы похожих объектов, необычные записи;
- **обучение с подкреплением** — агент действует в среде и учится по сигналам «хорошо» и «плохо» (игры, роботы, управление).

**По тому, что предсказываем:**

| Задача | Ответ | Пример для сервиса |
|---|---|---|
| **регрессия** | число | оценка цены автомобиля |
| **классификация** | класс из конечного набора | автомат или механика, если продавец не указал |
| **кластеризация** | группа (без заданных ответов) | сегменты покупателей с похожими запросами |
| ранжирование | порядок | какие объявления показать первыми |
| поиск аномалий | «необычно» / «обычно» | подозрительные объявления |

Одни и те же данные дают разные задачи. Предсказываем `Price` — регрессия; предсказываем `Transmission` — классификация:

```python
print('Регрессия: ответ — число, уникальных значений', df['Price'].nunique())
print('Классификация: ответ — класс')
print(df['Transmission'].value_counts(normalize=True).round(3))
```

## Ответ и его копии — не признаки

Признак можно брать в модель, только если он **известен в момент прогноза** и **не содержит сам ответ**. Если предсказывать коробку передач, колонка `AutoTransmission` — это тот же ответ в другом виде:

```python
same = (df['AutoTransmission'] == (df['Transmission'] == 'Automatic')).mean()
print('AutoTransmission совпадает с ответом в', round(same * 100), '% строк')
```

Модель с таким «признаком» покажет 100 % верных ответов и не будет стоить ничего: у нового объявления без указанной коробки этой колонки тоже нет. Такая ошибка называется **утечкой** — подробнее в уроке 5.4.

## Типичные ошибки

:::mistake Модель «понимает» автомобили
Модель находит закономерности только в тех признаках, которые ей дали. Состояние машины, комплектацию, цену сделки она не знает.
:::

:::mistake Ответ среди признаков
Цена в `X` при оценке цены или `AutoTransmission` при определении коробки дают идеальное качество на проверке и бесполезную модель.
:::

:::mistake Регрессия вместо классификации
Если закодировать классы числами 0 и 1 и предсказывать «число», получится 0,37 автомата. У классификации ответ — класс (или вероятность класса).
:::

:::mistake Прогноз = правило
Модель обучена по прошлым объявлениям. Если рынок изменится (сдвиг данных, урок 0.3), её нужно проверять и переобучать.
:::

## Что запомнить

- Машинное обучение находит зависимость $\hat y = f(x)$ по примерам $(x_i, y_i)$; цель — хорошие прогнозы на **новых** объектах.
- Объект — строка, признаки — колонки `X`, целевая переменная — `y`.
- С учителем (регрессия — число, классификация — класс), без учителя (кластеризация), с подкреплением (сигналы среды).
- Признак должен быть известен в момент прогноза и не быть копией ответа.
