## Зачем это нужно

В модуле 5 мы обучим первую модель машинного обучения — она будет оценивать цену автомобиля по его характеристикам. Новых инструментов будет много (Scikit-learn, разбиение выборки, метрики), но опираются они на знакомое:

- входные признаки `X` и целевая переменная `y` (урок 2.11);
- ошибки прогноза MAE и MAPE (урок 3.7) и медиана как «типичное» значение (урок 1.6);
- стандартизация столбцов через broadcasting (урок 1.10);
- случайный выбор строк генератором `default_rng` (урок 1.9) и доли категорий `value_counts` (урок 2.3).

Шесть коротких задач вернут их в рабочую память.

## Короткая памятка

```python
X = df[['Year', 'Distance']]                         # признаки — таблица, урок 2.11
y = df['Price']                                      # ответ — одна колонка
estimate = y.median()                                # одно число для всех
print('MAE медианы:', round((y - estimate).abs().mean()))                 # урок 3.7
Z = (X.to_numpy() - X.to_numpy().mean(axis=0)) / X.to_numpy().std(axis=0)  # стандартизация, урок 1.10
print('Средние после стандартизации:', Z.mean(axis=0).round(6))
print(df['Transmission'].value_counts(normalize=True).round(3))          # доли классов, урок 2.3
```

Доли классов понадобятся, когда ответ — не число, а класс (урок 5.1).
