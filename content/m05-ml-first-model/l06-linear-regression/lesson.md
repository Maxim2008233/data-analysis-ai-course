## Зачем это нужно

Ориентир ошибается в среднем на 6 000 евро. Теперь — первая настоящая модель: **линейная регрессия**, которая учитывает признаки. Начнём с одного признака — года выпуска, — чтобы видеть модель целиком: два числа, прямая на графике, понятный смысл. И сразу научимся главному навыку — **разбирать ошибки**: не только «насколько ошибается», но и «где и почему».

## Обучаем LinearRegression

Модель — прямая $\hat y = w_0 + w_1 \cdot \text{Year}$ (урок 5.2); `LinearRegression` подбирает параметры методом наименьших квадратов. Интерфейс тот же, что у ориентира: создать → `fit` → `predict`. Признаки модель ждёт **таблицей**, поэтому даже один признак берут двойными скобками:

```python
from sklearn.linear_model import LinearRegression

X_train_year = X_train[['Year']]          # таблица (n, 1), а не Series
X_valid_year = X_valid[['Year']]
year_model = LinearRegression()
year_model.fit(X_train_year, y_train)
print('Коэффициент w1:', round(year_model.coef_[0], 1), 'евро за год')
print('Свободный член w0:', round(year_model.intercept_))
```

- `coef_` — коэффициенты (по одному на признак): с каждым годом выпуска **прогноз** растёт на ≈ 717 евро;
- `intercept_` — свободный член, «прогноз для 0 года» ≈ −1,43 млн евро. Сам по себе он смысла не имеет: прямая используется только в диапазоне данных.

Коэффициент описывает модель, а не мир: он не доказывает, что «год выпуска добавляет к цене 717 евро». Год связан с пробегом, состоянием, поколением модели — всё это прямая «приписала» году.

## Прогноз и сравнение с ориентиром

```python
year_pred = year_model.predict(X_valid_year)
year_mae = mean_absolute_error(y_valid, year_pred)
print(f'MAE по году: {year_mae:.0f} евро')
print(f'MAE ориентира: {baseline_mae:.0f} евро')
print(f'Улучшение: {baseline_mae - year_mae:.0f} евро')
```

Один признак уже дал выигрыш около 900 евро. Но вспомните ориентир из задания 5.5.6 — медиана цены года выпуска даёт MAE ≈ 4 000. Прямая хуже простой таблицы медиан! Почему — покажет разбор ошибок.

## Разбор одной машины

Возьмём первую машину валидации. `iloc[[0]]` с двойными скобками оставляет **таблицу** из одной строки — такую `predict` принимает:

```python
one_car = X_valid_year.iloc[[0]]
one_pred = year_model.predict(one_car)[0]
one_true = y_valid.iloc[0]
print(one_car)
print(f'Цена: {one_true:.0f} евро, прогноз: {one_pred:.0f} евро, ошибка: {one_pred - one_true:+.0f} евро')
print('То же по формуле:', round(year_model.intercept_ + year_model.coef_[0] * one_car['Year'].iloc[0]))
```

Прогноз — это формула $w_0 + w_1 \cdot 2001$: модель не «знает» машину, она подставляет год в прямую. Для этой машины ошибка небольшая; посмотрим на все.

## Распределение ошибок

```python
errors = year_pred - y_valid.to_numpy()
print('Отрицательных прогнозов:', (year_pred < 0).sum(), '| самый низкий:', round(year_pred.min()))
print('Модуль ошибки: медиана', round(np.median(np.abs(errors))), '| 90 % машин — не больше', round(np.quantile(np.abs(errors), 0.9)))

fig, axes = plt.subplots(1, 2, figsize=(13, 3.8))
axes[0].hist(errors, bins=60, range=(-40_000, 20_000))
axes[0].set(title='Ошибки прогноза по году', xlabel='Прогноз − цена, евро', ylabel='Число машин')
grid = np.array([[1985], [2021]])
axes[1].scatter(X_valid['Year'], y_valid, s=4, alpha=0.15, color='gray')
axes[1].plot(grid[:, 0], year_model.predict(pd.DataFrame(grid, columns=['Year'])), 'r-', linewidth=2)
axes[1].axhline(0, color='black', linewidth=0.8)
axes[1].set(title='Прямая против облака цен', xlabel='Год выпуска', ylabel='Цена, евро', ylim=(-30_000, 80_000))
fig.tight_layout()
plt.show()
```

Что видно:

- **отрицательные цены**: для машин старше ≈ 1995 года прямая уходит ниже нуля — 385 прогнозов на валидации;
- **систематические ошибки**: цены растут с годом не по прямой, а всё круче — для новых дорогих машин прямая сильно занижает цену, для дешёвых — завышает;
- поэтому медиана каждого года (своё число для каждого года) работает лучше прямой (одна формула на все годы).

Это и есть разбор ошибок: он подсказывает, что делать дальше — добавить признаки (урок 5.7) или изменить вид зависимости (логарифм цены, урок 5.9).

## Типичные ошибки

:::mistake Series вместо таблицы
`X_train['Year']` — одна колонка (Series), `LinearRegression` выдаст ошибку о форме. Нужна таблица: `X_train[['Year']]`.
:::

:::mistake Коэффициент как причина
«Год добавляет 717 евро» — неверно. Коэффициент описывает прогноз модели; в год «спрятаны» пробег, состояние, поколение.
:::

:::mistake Смысл свободного члена
«Машина 0 года стоит −1,4 млн» — бессмыслица. За пределами диапазона данных прямая ничего не описывает.
:::

:::mistake Смотреть только на MAE
Средняя ошибка не показывает отрицательных цен и систематических перекосов. Посмотрите на распределение ошибок и на график.
:::

## Что запомнить

- `LinearRegression().fit(X_train[['Year']], y_train)`: `coef_` — изменение прогноза на единицу признака, `intercept_` — свободный член; признаки — таблицей.
- Сравнивайте модель с ориентирами: с константой и с простыми «табличными» оценками.
- Разбор ошибок: одна строка (`iloc[[0]]`), распределение ошибок, бессмысленные прогнозы (отрицательные цены), перекосы по группам.
- Прямая плохо описывает цену: цена растёт с годом нелинейно, а у старых машин прямая уходит ниже нуля.
