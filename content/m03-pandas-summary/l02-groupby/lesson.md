## Зачем это нужно

Второй вопрос аналитика — какая цена **типична для каждого сегмента**. В модуле 1 мы сравнивали две группы масками: «до 2015 года» и «с 2015 года». Но марок 22, кузовов 12, годов 65 — писать маску для каждой группы долго и легко ошибиться.

**Группировка** делает это одной строкой: «для каждой марки посчитай медианную цену». Это основной инструмент сводного анализа — им пользуются в каждом отчёте, а в модуле 7 с его помощью будут кодировать категории для моделей.

## Как работает groupby

Общий вид группировки:

```
df.groupby(колонки_групп)[колонка_значений].функция()
```

Pandas делает три шага: **разделяет** строки на группы по значениям колонки, **применяет** функцию к каждой группе и **объединяет** результаты в одну Series — группы становятся её индексом:

![Схема groupby](groupby.svg "Разделить → применить → объединить")

Для группы $g$ из $n_g$ объявлений средняя цена — обычное среднее, только по строкам этой группы:

$$
\bar{y}_g = \frac{1}{n_g}\sum_{i \in g} y_i.
$$

```python
mean_by_make = df.groupby('Make')['Price'].mean()
print(type(mean_by_make).__name__, '— групп:', len(mean_by_make))
mean_by_make.sort_values(ascending=False).head(5).round(0)
```

Результат — Series из 22 значений (по одному на марку), отсортированная по алфавиту марок. Чтобы найти самые дорогие марки, сортируем по значению (урок 2.2). Функции группировки — те же, что у колонки: `mean`, `median`, `min`, `max`, `sum`, `size`, `count`, `quantile`.

## Несколько статистик сразу: agg

`agg` применяет к каждой группе несколько функций и возвращает таблицу — по колонке на функцию:

```python
by_make = df.groupby('Make')['Price'].agg(['mean', 'median', 'size'])
by_make.sort_values('size', ascending=False).head(5).round(0)
```

`size` — число строк в группе. Среднее и медиана рядом сразу показывают «перекос»: у Mercedes среднее 13 491 евро, а медиана — 8 900: немного очень дорогих машин тянут среднее вверх.

## Группы по двум признакам

В `groupby` можно передать список колонок — тогда группа задаётся сочетанием значений, например «марка + год выпуска»:

```python
by_make_year = df.groupby(['Make', 'Year'])['Price'].agg(['mean', 'count'])
print('Групп «марка — год»:', len(by_make_year))
print('Групп из одной машины:', (by_make_year['count'] == 1).sum())
by_make_year.head()
```

797 групп, и в 70 из них — единственное объявление. Среднее по одной машине — это цена этой машины, а не «типичная цена Audi 1982 года». Размер группы важен — об этом весь следующий урок. Индекс такого результата состоит из двух уровней (марка и год); как с ним работать, разберём в уроке 3.4.

## Понятные имена: именованная агрегация

Когда статистик много, удобно сразу дать результатам понятные имена. Именованная агрегация записывается так: `имя_результата=('колонка', 'функция')`. Функцией может быть и своя короткая функция `lambda` — например, квартиль:

```python
make_summary = df.groupby('Make').agg(
    n=('Price', 'size'),
    mean_price=('Price', 'mean'),
    median_price=('Price', 'median'),
    q1=('Price', lambda s: s.quantile(0.25)),
    q3=('Price', lambda s: s.quantile(0.75)),
)
make_summary.sort_values('n', ascending=False).head(5).round(0)
```

`lambda s: s.quantile(0.25)` — функция «на месте»: получает цены группы `s` и возвращает их первый квартиль (урок 1.7). Такая таблица — готовая основа для отчёта: размер группы, центр и разброс цен.

## size и count — не одно и то же

`size` считает **все строки** группы, `count` — только **известные** (непустые) значения выбранной колонки. В нашей таблице пропусков нет, и они совпадают, но в других данных — нет:

```python
mini = pd.DataFrame({'make':  ['VW', 'VW', 'BMW', 'BMW', 'BMW'],
                     'price': [10, None, 30, 25, None]})
mini.groupby('make')['price'].agg(['size', 'count', 'mean'])
```

У BMW 3 строки, но известных цен 2 — и среднее посчитано по двум ценам. Когда пишете «средняя цена по N объявлениям», N — это `count`, а не `size`.

## Типичные ошибки

:::mistake Забыли выбрать колонку
`df.groupby('Make').mean()` пытается посчитать среднее по всем колонкам — и падает на текстовых (`TypeError`). Выбирайте колонку: `df.groupby('Make')['Price'].mean()`.
:::

:::mistake Рейтинг без размера группы
«Самая дорогая марка» по среднему из 2–3 объявлений ненадёжна. Выводите размер группы рядом со статистикой.
:::

:::mistake size вместо count
При пропусках `size` больше числа значений, по которым посчитано среднее. Для «по скольким ценам посчитано» нужен `count`.
:::

:::mistake Сортировка «по алфавиту»
Результат `groupby` упорядочен по названиям групп. Для рейтинга нужен `sort_values(ascending=False)`.
:::

## Что запомнить

- `df.groupby(колонки)[колонка].функция()` — статистика для каждой группы; группы становятся индексом.
- `agg([...])` — несколько статистик сразу; `agg(имя=('колонка', 'функция'))` — с понятными именами.
- Группировка по списку колонок задаёт группы сочетаниями значений; маленькие группы встречаются часто.
- `size` — все строки группы, `count` — известные значения; результат сортируют для рейтинга.
