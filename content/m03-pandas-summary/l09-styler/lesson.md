## Зачем это нужно

Сводная таблица — главный результат сводного анализа, и её читают другие люди: преподаватель, заказчик, коллега. Числа вида `13491.040973` с шестью знаками после запятой, непонятные названия колонок и десятки одинаковых серых ячеек заставляют читателя самому искать главное.

`df.style` — **оформление таблицы** в pandas (объект Styler): формат чисел, заголовок, цветовая шкала, полосы в ячейках, выделение максимума и пропусков. Важно: Styler меняет **только отображение** — сами числа в таблице остаются прежними.

## Таблица для оформления

Соберём таблицу десяти самых крупных марок (урок 3.2) и дадим колонкам понятные русские названия с единицами:

```python
make_summary = df.groupby('Make').agg(
    n=('Price', 'size'), mean_price=('Price', 'mean'), median_price=('Price', 'median'),
    q1=('Price', lambda s: s.quantile(0.25)), q3=('Price', lambda s: s.quantile(0.75)))
table = make_summary.nlargest(10, 'n').rename(columns={
    'n': 'Записей', 'mean_price': 'Средняя цена, евро', 'median_price': 'Медиана, евро',
    'q1': 'Q1, евро', 'q3': 'Q3, евро'})
table
```

`nlargest(10, 'n')` — десять строк с наибольшим числом записей (урок 2.2).

## Читаемые числа и заголовок

`format` задаёт отображение чисел: `precision=0` — без знаков после запятой, `thousands=' '` — пробел между разрядами, `na_rep='—'` — как показывать пропуски. `set_caption` добавляет заголовок таблицы:

```python
table.style.format(precision=0, thousands=' ', na_rep='—').set_caption('Топ-10 марок по числу объявлений')
```

`13491.040973` превратилось в `13 491` — читается сразу. Методы Styler можно писать цепочкой: каждый возвращает тот же Styler с ещё одним оформлением.

## Цветовая шкала

`background_gradient` раскрашивает ячейки: чем больше значение, тем темнее цвет. `subset` выбирает колонки, `cmap` — палитру, `axis=None` — одна общая шкала для всех выбранных колонок (иначе каждая колонка красится по своей шкале):

```python
(table.style
     .format(precision=0, thousands=' ')
     .background_gradient(subset=['Средняя цена, евро', 'Медиана, евро', 'Q1, евро', 'Q3, евро'],
                          cmap='YlOrRd', axis=None))
```

Тёмная ячейка — бо́льшая цена среди показанных групп. Цвет **не означает**, что марка «лучше» или «выгоднее» — только что цена выше.

## Полосы в ячейках и выделение максимума

`bar` рисует внутри ячеек полосы, пропорциональные значению, — таблица превращается в маленькую столбчатую диаграмму. `highlight_max` выделяет наибольшее значение колонки; `props` задаёт оформление выделения CSS-свойствами:

```python
(table.style
     .format(precision=0, thousands=' ')
     .bar(subset=['Записей'], color='#7aa6d8')
     .highlight_max(subset=['Медиана, евро'], props='background-color: #fff3b0; color: #222'))
```

Полоса в колонке «Записей» сразу показывает размер группы — тот самый, без которого нельзя доверять медиане (урок 3.3). Цвет текста в `props` задан явно, чтобы выделенная ячейка читалась и в тёмной теме.

## Пропуски в сводной таблице

В сводной цен пустая ячейка значит «нет объявлений такого сочетания» (урок 3.5). `highlight_null` подсвечивает такие ячейки, а `na_rep` показывает вместо `nan` понятный прочерк:

```python
fuel_prices = df.pivot_table(index='Make', columns='Fuel_type', values='Price', aggfunc='median').reindex(table.index)
(fuel_prices.style
     .format(precision=0, thousands=' ', na_rep='—')
     .highlight_null(props='background-color: #fff3b0; color: #222')
     .set_caption('Медианная цена по марке и топливу, евро; — нет объявлений'))
```

`reindex(table.index)` оставляет строки в порядке нашей таблицы. Жёлтая ячейка с прочерком — это **не нулевая цена**, а отсутствие данных; в подписи таблицы это стоит сказать прямо.

:::info Styler — только для показа
Объект `table.style` не таблица: считать по нему средние или фильтровать строки нельзя. Все расчёты — по исходному DataFrame, а Styler — последний шаг перед показом. Проверить можно так: `table.style.data is table` — Styler хранит ссылку на те же данные.
:::

## Типичные ошибки

:::mistake Считать по Styler
`table.style.format(...).mean()` — ошибка: у Styler нет методов таблицы. Сначала расчёты на DataFrame, потом оформление.
:::

:::mistake Шкала «каждая колонка сама по себе»
Без `axis=None` каждая колонка раскрашивается по своей шкале: одинаковый цвет в «Q1» и «Q3» означает разные цены. Для сравнимых колонок задайте общую шкалу.
:::

:::mistake Цвет как оценка
Тёмная ячейка — бо́льшее значение, а не «лучше». Подпишите, что означает цвет.
:::

:::mistake Ноль вместо прочерка
`fillna(0)` перед оформлением превращает «нет данных» в «0 евро». Оставляйте пропуски и показывайте их через `na_rep` и `highlight_null`.
:::

## Что запомнить

- `df.style` меняет только отображение; расчёты — всегда по исходному DataFrame.
- `format(precision=0, thousands=' ', na_rep='—')` и `set_caption(...)` — минимальное оформление отчёта.
- `background_gradient(subset=..., cmap=..., axis=None)` — общая цветовая шкала; цвет означает величину, а не «лучше».
- `bar(subset=...)` — полосы в ячейках (удобно для размера группы), `highlight_max` / `highlight_null` — выделение; цвет текста задают явно через `props`.
