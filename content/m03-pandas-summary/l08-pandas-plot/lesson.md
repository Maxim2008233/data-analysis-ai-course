## Зачем это нужно

Таблица из нескольких десятков средних цен по годам — это стена чисел, а линия на графике сразу показывает форму: где цена растёт, где провал, где выброс. График — быстрый способ **проверить вывод** из сводной таблицы и показать его другим.

У каждой Series и DataFrame в pandas есть метод `plot()`: результат группировки превращается в график одной строкой. Подробная настройка графиков (оси, цвета, несколько графиков на одной картинке, Seaborn, интерактивные графики) — тема модуля 4; здесь — быстрые графики для разведочного анализа.

## Линия из результата группировки

Посчитаем среднюю цену Mercedes по годам выпуска и нарисуем её. По оси X pandas берёт **индекс** Series — здесь это годы, по оси Y — значения:

```python
make = 'Mercedes'
by_year = df[df['Make'] == make].groupby('Year')['Price'].mean()
print('Индекс — годы:', by_year.index[:5].tolist(), '…')
by_year.plot();
```

Точка с запятой в конце скрывает служебный текст объекта графика — остаётся только картинка.

:::warning Линия — не динамика цен
Линия соединяет **разные группы машин**: Mercedes 2010 года и Mercedes 2011 года — разные автомобили одной выборки. Это не изменение цены во времени: дат объявлений в данных нет. Правильная подпись — «средняя цена по году выпуска».
:::

## Читаемый график

График без подписей непонятен никому, кроме автора. Минимальный набор: заголовок, подписи осей с единицами, сетка; маркеры показывают, где настоящие точки, а где — просто соединяющая линия:

```python
by_year.plot(marker='o', figsize=(10, 3), grid=True,
             title=f'Средняя цена {make} по годам выпуска',
             xlabel='Год выпуска', ylabel='Средняя цена, евро');
```

`figsize=(ширина, высота)` задаёт размер в дюймах. Вытянутая по горизонтали картинка удобна для длинного ряда годов.

## Столбцы для категорий

Для категорий (марки, кузова) линия бессмысленна: между Toyota и BMW нет «промежуточных» значений. Нужны **столбцы** — `kind='bar'`. Покажем 10 самых частых марок (урок 2.3):

```python
top = df['Make'].value_counts().head(10)
top.plot(kind='bar', figsize=(9, 3), rot=45,
         title='Число объявлений: 10 самых частых марок', xlabel='Марка', ylabel='Число объявлений');
```

`rot=45` поворачивает подписи по оси X, чтобы длинные названия не налезали друг на друга. Столбцы удобнее всего читать, когда они отсортированы — `value_counts()` уже вернул их по убыванию.

## Логарифмическая шкала

Когда значения различаются в десятки раз, мелкие детали тонут. На **логарифмической** шкале одинаковые расстояния означают одинаковое **отношение**: от 1 000 до 10 000 — столько же, сколько от 10 000 до 100 000. Рост «в 2 раза за N лет» превращается в прямую:

```python
by_year.plot(marker='o', figsize=(10, 3), grid=True, logy=True,
             title=f'Средняя цена {make} по годам выпуска (логарифмическая шкала)',
             xlabel='Год выпуска', ylabel='Средняя цена, евро');
```

$$
\log_{10} 1\,000 = 3,\qquad \log_{10} 10\,000 = 4,\qquad \log_{10} 100\,000 = 5 \quad \text{(равные шаги на шкале)}.
$$

Логарифмическую шкалу обязательно подписывают: читатель должен знать, что расстояния на ней — не разности, а отношения.

## Несколько рядов: DataFrame.plot

У сводной таблицы несколько колонок — `plot` нарисует их все, по ряду на колонку, с легендой. Сравним медианные цены автоматов и механики у самых частых марок (урок 3.4):

```python
price_pivot = df.pivot_table(index='Make', columns='Transmission', values='Price', aggfunc='median')
price_pivot.loc[top.index].plot(kind='bar', figsize=(10, 3), rot=45,
                                title='Медианная цена: автомат и механика',
                                xlabel='Марка', ylabel='Медианная цена, евро');
```

Пары столбцов сразу показывают, у каких марок разница больше. Помните оговорку урока 3.4: машины с автоматом в среднем новее — разница медиан не равна «стоимости коробки».

| Вопрос | График | Код |
|---|---|---|
| Как значение меняется по упорядоченному признаку (год)? | линия | `s.plot(marker='o')` |
| Сравнить категории (марки, кузова) | столбцы | `s.plot(kind='bar')` |
| Несколько рядов по категориям | сгруппированные столбцы | `pivot.plot(kind='bar')` |
| Значения различаются в десятки раз | логарифмическая шкала | `logy=True` |

## Типичные ошибки

:::mistake Линия для категорий
Линия между Toyota и BMW создаёт ложное впечатление «перехода». Для категорий — столбцы.
:::

:::mistake График без подписей
Без заголовка и подписей осей с единицами («цена, евро») график нельзя понять и проверить.
:::

:::mistake Линия по годам как «динамика рынка»
Средняя цена по году выпуска — это сравнение разных машин, а не изменение цен со временем.
:::

:::mistake Неподписанная логарифмическая шкала
Читатель решит, что расстояния — это разности, и неверно оценит различия. Пишите в заголовке, что шкала логарифмическая.
:::

## Что запомнить

- `s.plot()` рисует линию по индексу Series; `kind='bar'` — столбцы; у DataFrame — по ряду на колонку с легендой.
- Минимум подписей: `title`, `xlabel`, `ylabel` с единицами; `grid=True`, `marker='o'`, `rot=45`, `figsize`.
- Линия — для упорядоченного признака, столбцы — для категорий; линия по году выпуска — не динамика цен.
- `logy=True` — логарифмическая шкала для значений, различающихся в разы; её обязательно подписывают.
