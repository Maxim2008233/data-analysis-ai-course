## Зачем это нужно

Гистограмма всех цен смешивает разные машины: новые и старые, седаны и пикапы, автоматы и механику. То, что в общей куче выглядит выбросом, внутри своей группы может быть обычным значением — и наоборот. Поэтому после распределения одного признака смотрят **условное распределение** — распределение признака **внутри каждой группы**. Оно отвечает на вопросы «чем различаются сегменты?» и «одинаковы ли для них границы обычных значений?».

## Гистограммы по группам

Параметр `hue=` раскрашивает гистограмму по категории, а `multiple=` задаёт, как сложить группы:

```python
fig, axes = plt.subplots(1, 2, figsize=(13, 3.5))
sns.histplot(data=df, x='Distance', hue='Transmission', multiple='stack', bins=20, ax=axes[0])
axes[0].set(title="multiple='stack': группы друг на друге", xlabel='Пробег, км', ylabel='Число объявлений')
sns.histplot(data=df, x='Distance', hue='Transmission', multiple='fill', bins=20, ax=axes[1])
axes[1].set(title="multiple='fill': доля групп в каждом интервале", xlabel='Пробег, км', ylabel='Доля')
fig.tight_layout()
plt.show()
```

- `'stack'` ставит столбики групп друг на друга: высота стопки — все объявления интервала, части — вклад групп;
- `'fill'` растягивает каждую стопку до 1 — видно, как меняется **доля** автоматов с пробегом;
- по умолчанию (`'layer'`) гистограммы полупрозрачно накладываются — удобно для двух групп с похожим числом записей.

Справа видно, что с ростом пробега доля автоматов падает: среди машин с пробегом до 100 тыс. км их больше половины, а среди машин с пробегом больше 400 тыс. км — около четверти.

## Боксплоты по категориям

Боксплоты компактнее гистограмм: они прячут мелкие, возможно случайные, детали и оставляют главное — центр и разброс каждой группы. Упорядочим кузова по медианной цене, чтобы сравнение читалось слева направо:

```python
order = df.groupby('Style')['Price'].median().sort_values(ascending=False).index
fig, ax = plt.subplots(figsize=(12, 3.5))
sns.boxplot(data=df, x='Style', y='Price', order=order, showfliers=False, ax=ax)
ax.set(title='Цена по типу кузова (крайние точки скрыты)', xlabel='Тип кузова', ylabel='Цена, евро')
ax.tick_params(axis='x', rotation=45)
ax.grid(axis='y', alpha=0.25)
plt.show()
print(df['Style'].value_counts()[['Pickup', 'Roadster', 'Sedan']])
```

`showfliers=False` прячет точки за усами, но квартили посчитаны по всем записям. Читаем: пикапы, кроссоверы и SUV дороже остальных, хэтчбеки и минивэны — дешевле. Но пикапов 124, а родстеров всего 23: их медианы ненадёжны (урок 3.3), и на графике это стоит оговорить.

## «Норма» зависит от группы

Сравним цены по категории пробега в год и посчитаем, сколько «выбросов» по правилу 1,5·IQR в каждой группе:

```python
order = ['Small', 'Medium', 'Large']
fig, ax = plt.subplots(figsize=(9, 3.5))
sns.boxplot(data=df, x='km_year_cat', y='Price', order=order, ax=ax)
ax.set(title='Цена по категории пробега в год', xlabel='Пробег в год', ylabel='Цена, евро', yscale='log')
plt.show()

for name in order:
    group = df[df['km_year_cat'] == name]
    q1, q3 = group['Price'].quantile([0.25, 0.75])
    high = q3 + 1.5 * (q3 - q1)
    out = group[group['Price'] > high]
    print(f'{name}: выше уса {len(out)} из {len(group)}, медианный год этих машин — {out["Year"].median():.0f}')
```

В группе `Small` (до 10 000 км в год) «выбросов» больше всего, и это в основном машины 2018 года: новые машины с маленьким пробегом стоят дорого, это не ошибки. Значит, одно правило фильтрации цены для всех групп не годится: для малого пробега дорогие машины — норма, для среднего и большого цена в сотни тысяч евро — повод проверить запись. `yscale='log'` в `ax.set` — логарифмическая ось Y, чтобы дорогие машины не сжали ящики.

## Панели по группам: catplot

Чтобы сравнить одну и ту же картину в нескольких сегментах, рисуют **панели** — по одной на группу, с общей шкалой. Функция `sns.catplot` делает это одним вызовом: `col='Make'` — панель на каждую марку.

```python
top6 = df.loc[df['Make'] != 'Rare', 'Make'].value_counts().head(6).index
g = sns.catplot(data=df[df['Make'].isin(top6)], x='km_year_cat', y='Price', col='Make',
                col_order=list(top6), order=['Small', 'Medium', 'Large'],
                kind='box', showfliers=False, col_wrap=3, height=3, aspect=1.1)
g.set_titles('{col_name}')
g.set_axis_labels('Пробег в год', 'Цена, евро')
g.figure.suptitle('Цена по категории пробега в шести самых частых марках', y=1.03)
plt.show()
```

- `catplot` создаёт **собственный рисунок** — оси ему не передают; результат — объект FacetGrid с методами оформления;
- `col_wrap=3` — по три панели в ряд, `col_order` — порядок панелей, `order` — порядок групп внутри панели;
- общая шкала Y (по умолчанию) делает панели честно сравнимыми: у BMW и Mercedes ящики выше, у Opel — ниже всех.

`Rare` исключили: это не марка, а группа из десятков редких марок, сравнивать её с остальными бессмысленно.

## Тепловая карта долей

Вопрос из плана урока 4.1 — «как различается состав топлива внутри марок» — это таблица долей `crosstab(..., normalize='index')` (урок 3.5). Глазами её читать удобнее в виде **тепловой карты**: цвет показывает величину, подписи — точные значения.

```python
top6 = df.loc[df['Make'] != 'Rare', 'Make'].value_counts().head(6).index
brands = df[df['Make'].isin(top6)]
shares = pd.crosstab(brands['Make'], brands['Fuel_type'], normalize='index')
fig, ax = plt.subplots(figsize=(9, 3.5))
sns.heatmap(shares, annot=True, fmt='.0%', cmap='Blues', ax=ax)
ax.set(title='Доля типов топлива внутри марки', xlabel='Тип топлива', ylabel='Марка')
plt.show()
```

`fmt='.0%'` — подписи в процентах без знаков после запятой. Сразу видно сегменты: Renault — почти одни дизели, у Toyota — четверть гибридов. Знаменатель доли («внутри марки») указан в заголовке — без него таблицу легко прочитать неправильно.

## Типичные ошибки

:::mistake Один фильтр для всех групп
Граница «обычной» цены для новых машин с малым пробегом и для старых с большим разная. Смотрите условные распределения и уточняйте фильтры по группам.
:::

:::mistake Боксплоты в случайном порядке
Группы без `order` идут в порядке появления в данных. Упорядочьте их по медиане или по смыслу (`Small`, `Medium`, `Large`).
:::

:::mistake Количества вместо долей на тепловой карте
У частых марок все числа больше — карта покажет размер марки, а не состав. Для сравнения состава — доли внутри строки: `normalize='index'`.
:::

:::mistake Панели с разными шкалами
Если у панелей разные шкалы Y, высокий ящик на одной может означать меньшие цены, чем низкий на другой. У `catplot` шкала общая по умолчанию — не отключайте её без причины.
:::

## Что запомнить

- Условное распределение — распределение признака внутри групп: `hue=` с `multiple='stack'` или `'fill'`, боксплоты `sns.boxplot(data=df, x='группа', y='число', order=...)`.
- Группы упорядочивают по медиане или по смыслу; у малых групп статистики ненадёжны.
- «Норма» зависит от группы: фильтры и выводы уточняют по сегментам.
- `sns.catplot(..., col='Make', kind='box', col_wrap=3)` — панели по группам с общей шкалой; создаёт свой рисунок.
- Состав сегментов — тепловая карта долей `sns.heatmap(crosstab(..., normalize='index'), annot=True, fmt='.0%')`.
