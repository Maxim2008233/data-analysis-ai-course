## Зачем это нужно

Ответ на вопрос «какие марки представлены?» (урок 4.1) — столбчатая диаграмма. Но столбцы можно нарисовать так, что заказчик будет полминуты разбирать повёрнутые подписи и сравнивать на глаз соседние высоты. А можно — так, что вывод виден сразу. Разница — в нескольких решениях: сколько категорий показать, в каком порядке, как подписать и чем выделить главное.

## Было: все столбцы подряд

Так выглядит первый вариант «в лоб» — все значения `Make`, вертикальные столбцы:

```python
counts = df['Make'].value_counts()
fig, ax = plt.subplots(figsize=(10, 3.5))
ax.bar(counts.index, counts.values)
ax.set(title='Количество автомобилей по маркам', xlabel='Марка', ylabel='Количество')
ax.tick_params(axis='x', rotation=60)
plt.show()
```

Что мешает читать:

- 22 столбца — подписи приходится поворачивать и читать «боком»;
- соседние столбцы почти одинаковые — без чисел их не различить;
- непонятно, какая это **доля** всех объявлений;
- `Rare` стоит в одном ряду с марками, хотя это группа из десятков редких марок (урок 2.10).

## Стало: топ-10, горизонтально, с подписями

Оставим десять самых частых значений, развернём столбцы горизонтально — длинные названия читаются без поворота — и подпишем у каждого число и долю:

```python
top = df['Make'].value_counts().head(10).sort_values()   # по возрастанию: barh рисует снизу вверх
fig, ax = plt.subplots(figsize=(9, 4.5))
bars = ax.barh(top.index, top.values, color='#3973a5')
ax.bar_label(bars, labels=[f'{n} ({100 * n / len(df):.1f}%)' for n in top], padding=4)
ax.set(title='Топ-10 марок по числу объявлений', xlabel='Число объявлений')
ax.set_xlim(0, top.max() * 1.3)        # запас справа, чтобы подписи поместились
ax.grid(axis='x', alpha=0.25)
plt.show()
print('Остальные марки:', len(df) - top.sum(), 'объявлений')
```

Разберём решения по очереди:

1. `head(10)` — только главное; про остальные скажем одной строкой под графиком.
2. `sort_values()` по **возрастанию**: `barh` рисует первую категорию снизу, поэтому самый большой столбец окажется сверху — там, куда смотрят в первую очередь.
3. `ax.bar_label(bars, labels=...)` пишет текст у каждого столбца; список подписей строится f-строкой: число и доля всех объявлений в процентах.
4. `ax.set_xlim(0, max * 1.3)` оставляет место для подписей; ось столбцов **начинается с нуля**.
5. Сетка только вдоль оси значений — `ax.grid(axis='x')`: горизонтальные линии между столбцами не нужны.

:::warning Столбцы — всегда от нуля
Длина столбца — это и есть значение. Если ось начинается, например, с 1 000, столбец 2 000 выглядит вдвое длиннее, чем 1 500, хотя больше всего на треть. У линейных графиков ось можно не начинать с нуля, у столбцов — нельзя.
:::

## Цвет со смыслом

Цвет — самый сильный сигнал на графике, поэтому его тратят только на смысл. Один ряд значений — один цвет. Если вывод касается одной категории, её выделяют **акцентом**, а остальные делают серыми:

```python
colors = ['tab:orange' if name == 'Toyota' else 'lightgray' for name in top.index]
fig, ax = plt.subplots(figsize=(9, 4.5))
bars = ax.barh(top.index, top.values, color=colors)
ax.bar_label(bars, padding=4)
ax.set(title='Toyota — вторая по числу объявлений марка', xlabel='Число объявлений')
ax.set_xlim(0, top.max() * 1.2)
plt.show()
```

Список `colors` строится так же, как список подписей: по одному цвету на каждую категорию в том же порядке, что и столбцы. Именованные цвета Matplotlib — `'tab:blue'`, `'tab:orange'`, `'lightgray'`, `'gray'` — или код вида `'#3973a5'`.

| Задача цвета | Как |
|---|---|
| один ряд значений | один цвет для всех столбцов |
| выделить главную категорию | акцент + серый для остальных |
| показать группу «прочее» | светло-серый (`'lightgray'`) |
| различить несколько рядов | разные хорошо различимые цвета (`tab:blue`, `tab:orange`, …) |

## «Остальные» — отдельным серым столбцом

Иногда важно показать не только лидеров, но и сколько осталось за ними. Добавим к пяти самым частым значениям строку «Остальные» и нарисуем её светло-серой внизу:

```python
parts = df['Make'].value_counts().head(5)
parts['Остальные'] = len(df) - parts.sum()       # новая метка в Series
colors = ['#3973a5'] * 5 + ['lightgray']
fig, ax = plt.subplots(figsize=(9, 3.5))
bars = ax.barh(parts.index, parts.values, color=colors)
ax.invert_yaxis()                                # первая строка сверху
ax.bar_label(bars, labels=[f'{100 * n / len(df):.1f}%' for n in parts], padding=4)
ax.set(title='Пять самых частых значений Make — меньше половины объявлений', xlabel='Число объявлений')
ax.set_xlim(0, parts.max() * 1.2)
plt.show()
```

Присваивание по новой метке `parts['Остальные'] = …` добавляет элемент в конец Series. Здесь порядок — «как в таблице» (по убыванию, «Остальные» в конце), поэтому вместо сортировки ось переворачиваем: `ax.invert_yaxis()`.

## Типичные ошибки

:::mistake Все категории подряд
Двадцать с лишним столбцов с повёрнутыми подписями не читаются. Покажите топ-N и подпишите, сколько записей осталось.
:::

:::mistake Несортированные столбцы
В случайном порядке сравнивать длины трудно. Сортируйте: для `barh` — по возрастанию (или `invert_yaxis()`).
:::

:::mistake Радуга
Свой цвет у каждого столбца одного ряда не несёт смысла и отвлекает. Один цвет; акцент — только для того, о чём вывод.
:::

:::mistake Ось столбцов не с нуля
Обрезанная ось искажает пропорции: маленькие различия выглядят огромными.
:::

## Мини-квиз

```quiz
- q: "Почему перед `ax.barh` значения сортируют **по возрастанию**?"
  options:
    - barh рисует первую категорию снизу — так самый большой столбец окажется сверху
    - Иначе barh выдаст ошибку
    - Чтобы подписи были по алфавиту
  answer: 0
  explain: Горизонтальные столбцы рисуются снизу вверх; по возрастанию — значит, лидер сверху. Другой способ — `ax.invert_yaxis()`.
- q: Как лучше выделить на графике марку, о которой вывод?
  options:
    - Дать каждой марке свой яркий цвет
    - Выделить её акцентным цветом, остальные сделать серыми
    - Нарисовать её столбец в 3D
  answer: 1
  explain: Акцент на сером фоне сразу направляет взгляд; радуга этого не делает.
- q: "Зачем `ax.set_xlim(0, top.max() * 1.3)`?"
  options:
    - Чтобы у самого длинного столбца поместилась подпись и ось начиналась с нуля
    - Чтобы увеличить значения на 30 %
    - Чтобы скрыть маленькие столбцы
  answer: 0
  explain: Значения не меняются — меняется только видимый диапазон оси.
```

## Что запомнить

- Для категорий — топ-N горизонтальных столбцов, отсортированных так, чтобы лидер был сверху.
- `bars = ax.barh(...)`, затем `ax.bar_label(bars, labels=[...], padding=4)`; запас справа — `ax.set_xlim(0, max * 1.3)`.
- Ось столбцов начинается с нуля; сетка — только вдоль оси значений.
- Цвет — сигнал: один ряд — один цвет, главное — акцентом, остальное — серым, «Остальные» — светло-серым.
