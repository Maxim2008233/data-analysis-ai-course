## Зачем это нужно

**Распознавание речи** превращает речевой сигнал в текст, **синтез речи** — текст в звук (лекция, слайд 34). Вместе они работают в умных колонках, голосовых помощниках, контакт-центрах, автоматическом переводе видео и цифровых аватарах (слайды 35–39).

Задачи распознавания бывают разной трудности (слайд 40):

- **фиксированный набор слов** — команды: «включи свет», «громче»;
- **заданный сценарий** — контакт-центр, где ответы клиента предсказуемы;
- **поиск ключевых слов** — «купить билеты на самолёт» в потоке речи;
- **произвольная речь** — самое трудное.

Голосовой бот из урока 11.8 использовал готовые сервисы. Сегодня заглянем внутрь: как выглядит звук для модели, как она выбирает слова, как меряют её ошибки и почему синтезатору нужно готовить текст.

## Звук раскладывается на частоты

Любой звук можно представить как сумму синусоид разных частот. **Преобразование Фурье** находит, каких частот сколько в куске звука. Результат — **спектр**: амплитуда для каждой частоты. Составим «аккорд» из двух нот с шумом и разложим его:

```python
rate8 = 8000
t = np.arange(rate8) / rate8                                # одна секунда
chord = (np.sin(2 * np.pi * 440 * t) + 0.5 * np.sin(2 * np.pi * 660 * t)
         + 0.1 * np.random.default_rng(0).normal(size=len(t)))
spec = np.abs(np.fft.rfft(chord)) / len(t) * 2              # амплитуда каждой частоты
freqs = np.fft.rfftfreq(len(t), d=1 / rate8)                 # какие это частоты, Гц
top = np.argsort(spec)[::-1][:3]
print('самые сильные частоты:', [(float(freqs[i]), round(float(spec[i]), 3)) for i in top])
print('шаг по частоте:', freqs[1], 'Гц')

plt.figure(figsize=(8, 2.6))
plt.plot(freqs, spec)
plt.xlim(0, 1000)
plt.xlabel('частота, Гц')
plt.ylabel('амплитуда')
plt.title('Спектр аккорда 440 + 660 Гц с шумом')
plt.show()
```

`np.fft.rfft` считает преобразование Фурье для вещественного сигнала, `np.abs` превращает результат в амплитуды. `rfftfreq` подписывает частоты: от 0 до половины частоты дискретизации (4000 Гц) с шагом 1 Гц. Шаг равен единице, делённой на длительность куска. Чтобы различать частоты точнее, кусок нужен длиннее. Пики стоят ровно на 440 и 660 Гц с амплитудами 1 и 0,5, а шум размазан по всем частотам понемногу.

## Спектрограмма: частоты во времени

У речи частоты всё время меняются: каждый звук — свой спектр. Поэтому запись режут на короткие **кадры** по 20–25 мс, у каждого считают спектр и рисуют спектры подряд. Это **спектрограмма**: время по горизонтали, частота по вертикали, яркость — громкость. Возьмём запись `recording.wav` из урока 11.8 — «Тестовая проверка записи»:

```python
frame, hop = 1024, 480                                       # кадр 21 мс, шаг 10 мс при 48 000 Гц
starts = np.arange(0, len(x) - frame + 1, hop)               # где начинается каждый кадр
frames = x[starts[:, None] + np.arange(frame)]               # таблица кадров: строка — кадр
S = np.abs(np.fft.rfft(frames * np.hanning(frame), axis=1))  # спектр каждого кадра
freqs = np.fft.rfftfreq(frame, d=1 / rate)
print('кадров:', S.shape[0], '| частот в спектре:', S.shape[1], '| шаг по частоте:', round(freqs[1], 1), 'Гц')

db = 20 * np.log10(S + 1e-9)                                 # громкость в децибелах
fig, ax = plt.subplots(2, 1, figsize=(9, 5), sharex=True)
ax[0].plot(np.arange(len(x)) / rate, x, lw=0.4)
ax[0].set_ylabel('отсчёт')
ax[1].imshow(db.T, origin='lower', aspect='auto', cmap='magma',
             extent=[0, len(x) / rate, 0, rate / 2], vmin=db.max() - 70, vmax=db.max())
ax[1].set_ylim(0, 6000)
ax[1].set_ylabel('частота, Гц')
ax[1].set_xlabel('время, с')
plt.tight_layout()
plt.show()
```

Таблицу кадров собирает broadcasting (урок 1.10): столбец начал кадров плюс строка сдвигов `0…1023` дают номера отсчётов каждого кадра. Перед преобразованием кадр умножают на **окно Ханна** `np.hanning` — плавную «шапочку», которая гасит края кадра. Без окна резкий обрыв на краях добавил бы в спектр частоты, которых в звуке нет. Громкость рисуют в **децибелах** — логарифмической шкале, как слышит ухо. Иначе тихие звуки на картинке не разглядеть.

Что видно на спектрограмме:

- **горизонтальные полосы** в гласных — гармоники голоса: частота основного тона и кратные ей. Их рисунок меняется от звука к звуку, по нему и различают гласные;
- **светлые столбы до 6000 Гц** около 1,3 и 2,5 секунды — шумные согласные «т», «с», «з» в словах «тестовая» и «записи». Энергии у них мало, зато она на высоких частотах;
- **тёмный фон** — тишина до и после фразы.

Почти вся энергия речи — ниже 4000 Гц. Но согласным нужны и высокие частоты, поэтому для распознавания запись обычно берут с частотой 16 000 отсчётов в секунду: так сохраняются частоты до 8000 Гц.

## Как распознают речь

Лекция делит распознавание на этапы (слайд 42): речь режут на короткие промежутки; для каждого вычисляют характеристики звука — по сути, тот же спектр; по ним определяют фонемы — звуки языка; из фонем собирают слова, из слов — предложения.

Работают три модели (слайд 43):

| Модель | Что делает | Пример |
|---|---|---|
| **акустическая** | по кадрам оценивает, какие звуки произносятся | «скорее [л], чем [в]» |
| **лексикон** (словарь) | знает, какие слова существуют и из каких звуков они состоят | «лес» = [л'эс] |
| **языковая** | знает, какие последовательности слов правдоподобны | «случайный лес» встречается, «случайный вес» — нет |

Языковая модель нужна потому, что одинаковые звуки складываются в разные слова. Пример из лекции (слайд 31):

```python
a, b = 'я икры съем ещё', 'я и крыс ем ещё'
print('звучат одинаково:', a.replace(' ', '').replace('ъ', '') == b.replace(' ', '').replace('ъ', ''))

sentences = []                                   # языковая модель на парах слов из текстов курса (урок 9.1)
with open('course_docs.json', encoding='utf-8') as fh:
    for d in json.load(fh):
        for s in re.split(r'[.!?\n]+', d['section'] + '. ' + d['text']):
            words = re.findall(r'[а-яё]+', s.lower())
            if words:
                sentences.append(words)
uni = Counter(w for s in sentences for w in s)
bi = Counter(p for s in sentences for p in zip(s, s[1:]))
V = len(uni)

def lm_logprob(words):
    """Логарифм вероятности фразы: сумма по парам слов, к каждому счётчику +1."""
    return sum(math.log((bi[(u, v)] + 1) / (uni[u] + V)) for u, v in zip(words, words[1:]))

for phrase in ['что такое случайный лес', 'что такое случайный вес', 'что такое языковая модель', 'что такое языковая модуль']:
    print(f'{phrase:27} {lm_logprob(phrase.split()):7.2f}')
```

Без пробелов и твёрдого знака две фразы совпадают буква в букву: на слух их не различить. Выбрать помогает языковая модель — та же модель на парах слов, что в уроке 9.1. Вероятность фразы — произведение вероятностей пар, а логарифм превращает произведение в сумму. К каждому счётчику прибавляем 1, чтобы незнакомая пара не обнулила всю фразу. По текстам курса «случайный лес» правдоподобнее «случайного веса», а «языковая модель» — «языковой модуль»: разница в логарифмах около 2, то есть в 7–12 раз по вероятности. Про икру и крыс в курсе ничего нет, так что лекционный пример этой модели не по силам — для него нужна модель, обученная на текстах о жизни.

Итоговая оценка гипотезы — сумма двух логарифмов: акустического и языкового. Если акустическая модель сомневается между «лес» и «вес», решает языковая.

## Как мерить распознавание: WER

Качество распознавания меряют **долей ошибочных слов** — WER (word error rate). Это расстояние Левенштейна из урока 12.4, только по словам, а не по буквам, делённое на число слов эталона:

```python
def to_words(s):
    return re.findall(r'[a-zа-яё0-9]+', s.lower())          # без регистра и знаков препинания

def word_edits(ref, hyp):
    prev = list(range(len(hyp) + 1))
    for i in range(1, len(ref) + 1):
        cur = [i] + [0] * len(hyp)
        for j in range(1, len(hyp) + 1):
            cur[j] = min(prev[j] + 1, cur[j - 1] + 1, prev[j - 1] + (ref[i - 1] != hyp[j - 1]))
        prev = cur
    return prev[-1]

pairs = [('Что такое случайный лес?', 'что такое случайный вес'),
         ('Как работает GigaChat?', 'как работает гига чат'),
         ('Почему модель переобучилась?', 'почему модель пере обучилась'),
         ('Голосовой чат на Gradio', 'голосовой чат на radio'),
         ('Сколько эпох обучать нейросеть?', 'сколько эпох обучать нейросеть')]
total_edits = total_words = 0
for ref, hyp in pairs:
    e, k = word_edits(to_words(ref), to_words(hyp)), len(to_words(ref))
    total_edits, total_words = total_edits + e, total_words + k
    print(f'{ref:32} → {hyp:32} ошибок {e} из {k}, WER {e / k:.2f}')
print(f'WER по всем фразам: {total_edits} / {total_words} = {total_edits / total_words:.3f}')
```

Перед сравнением оба текста приводят к словам без регистра и знаков: распознаватель обычно не ставит заглавных букв, и это не ошибка. Название «GigaChat», записанное как «гига чат», стоит 2 ошибки: замена и вставка. «Голосовой чат на radio» — настоящая ошибка из ноутбука урока 11.8: незнакомое название Gradio распознаватель заменил похожим словом. WER по всем фразам считают как сумму ошибок, делённую на сумму слов, а не как среднее WER фраз: короткие фразы иначе весили бы слишком много.

## Синтез речи: сначала подготовить текст

Синтез — обратная задача, и у неё свои трудности (слайд 44). В тексте нет интонации и эмоций. Букв меньше, чем звуков: «замок» и «замок» пишутся одинаково, а звучат по-разному. Синтезатор работает по этапам (слайды 45–46):

1. **подготовка текста** — числа, сокращения и знаки словами, расстановка ударений;
2. **выбор голоса** (мужской, женский, разные персонажи — у Сбера это, например, Сбер, Джой и Афина) и **интонации** (нейтральная, радостная, деловая);
3. **генерация звука** нейросетью по подготовленному тексту.

Синтезатор не прочитает «440 Гц» и «74 %» — их надо написать словами:

```python
ONES = ['ноль', 'один', 'два', 'три', 'четыре', 'пять', 'шесть', 'семь', 'восемь', 'девять', 'десять',
        'одиннадцать', 'двенадцать', 'тринадцать', 'четырнадцать', 'пятнадцать', 'шестнадцать',
        'семнадцать', 'восемнадцать', 'девятнадцать']
TENS = ['', '', 'двадцать', 'тридцать', 'сорок', 'пятьдесят', 'шестьдесят', 'семьдесят', 'восемьдесят', 'девяносто']
HUNDREDS = ['', 'сто', 'двести', 'триста', 'четыреста', 'пятьсот', 'шестьсот', 'семьсот', 'восемьсот', 'девятьсот']

def say_number(k):
    """Число от 0 до 999 словами."""
    if k == 0:
        return 'ноль'
    h, rest = divmod(k, 100)
    parts = [HUNDREDS[h]] if h else []
    if rest >= 20:
        parts.append(TENS[rest // 10])
        if rest % 10:
            parts.append(ONES[rest % 10])
    elif rest:
        parts.append(ONES[rest])
    return ' '.join(parts)

text = 'Частота ноты ля — 440 Гц. Классификатор угадал 74 % разделов, ориентир — 11 %.'
naive = re.sub(r'(\d+) ?%', lambda m: say_number(int(m.group(1))) + ' процентов', text)
naive = re.sub(r'(\d+) ?Гц', lambda m: say_number(int(m.group(1))) + ' герц', naive)
print(naive)
```

`re.sub` с функцией вместо строки замены вызывает её для каждого совпадения: `m.group(1)` — число из скобок шаблона. Числа стали словами, но «семьдесят четыре процентов» — ошибка. В русском языке форма слова после числа зависит от последних цифр: один процент, два процента, пять процентов, двадцать один процент. Это правило вы напишете в задании.

Лекция отмечала, что синтезированный голос отличается от человеческого и его трудно слушать долго (слайд 47). Нейросетевой синтез с тех пор шагнул далеко: голос бывает почти неотличим от живого. Отсюда новые риски — подделки голоса, о них в уроке 12.6.

## Типичные ошибки

:::mistake Резать кадры без окна
Резкие края кадра добавляют в спектр частоты, которых в звуке нет. Умножайте кадр на окно Ханна перед преобразованием Фурье.
:::

:::mistake Считать WER без нормализации текста
«Что такое случайный лес?» и «что такое случайный лес» — одна и та же фраза. Если сравнивать строки с регистром и знаками, каждая заглавная буква станет «ошибкой» распознавания.
:::

:::mistake Считать, что языковая модель всегда права
Языковая модель тянет к частым фразам из своих текстов. Если человек сказал редкое, но правильное «случайный вес нейрона», а акустика уверена, побеждать должна акустика. Поэтому две оценки складывают, а не заменяют одну другой.
:::

## Что запомнить

- Преобразование Фурье раскладывает звук на частоты; спектрограмма — спектры коротких кадров подряд, с окном Ханна на каждом кадре.
- Распознавание: кадры → характеристики звука → акустическая модель (звуки) → словарь (слова) → языковая модель (правдоподобная фраза).
- Одинаково звучащие фразы различает языковая модель; итог — сумма акустической и языковой оценок.
- Качество распознавания — WER: расстояние Левенштейна по словам, делённое на число слов эталона, после приведения к словам без регистра и знаков.
- Синтез: подготовка текста (числа и сокращения словами в нужной форме, ударения) → голос и интонация → генерация звука.
