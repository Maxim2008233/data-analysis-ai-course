## Зачем это нужно

В мини-проекте 11.9 помощник по курсу отвечал на вопросы, набранные текстом. Теперь он должен понимать голос и картинки — стать **мультимодальным**. Модальность — вид данных: текст, звук, изображение. Детали у нас уже есть:

- голос → текст: распознавание речи и его проверка по WER (урок 12.5);
- поиск урока по вопросу и проверка поиска (уроки 11.1–11.2);
- выделение сущностей по словарю (урок 12.4);
- ответ голосом: подготовка текста для синтеза (урок 12.5);
- картинка → ответ: CLIP без обучения (урок 9.7);
- риски: что делать, когда модель не уверена (урок 12.6).

Соберём из них две ветки помощника и честно проверим каждую.

## Данные

Вопросы — 15 вопросов по курсу из проверочной части `test` урока 11.9, с уроками, где есть ответ. Настоящего распознавания речи в браузере нет. Поэтому для каждого вопроса записан вариант `heard` — так его мог бы распознать голосовой бот. Варианты составлены вручную по типичным ошибкам распознавания, которые мы видели в уроке 11.8:

- латинские термины записаны русскими буквами по звучанию: «фью шот», «эр эм эс и»;
- длинные редкие слова разорваны на части: «токен изатор», «бокс плот»;
- слова заменены похоже звучащими: «код» → «кот», «лес» → «вес».

## Почему не помогает исправитель опечаток

Первая мысль — пропустить распознанный текст через исправитель опечаток из урока 12.4. Проверим:

```python
def to_words(text):
    return re.findall(r'[a-zа-яё0-9]+', text.lower())

def levenshtein(a, b):
    prev = list(range(len(b) + 1))
    for i in range(1, len(a) + 1):
        cur = [i] + [0] * len(b)
        for j in range(1, len(b) + 1):
            cur[j] = min(prev[j] + 1, cur[j - 1] + 1, prev[j - 1] + (a[i - 1] != b[j - 1]))
        prev = cur
    return prev[-1]

def total_wer(refs, hyps):
    errors = sum(levenshtein(to_words(r), to_words(h)) for r, h in zip(refs, hyps))
    return errors / sum(len(to_words(r)) for r in refs)

counts = {}
for d in docs:
    for w in to_words(d['lesson_title'] + '. ' + d['section'] + '. ' + d['text']):
        counts[w] = counts.get(w, 0) + 1
vocab = {w: c for w, c in counts.items() if c >= 2}

def correct(word, max_d=2):
    if word in vocab:
        return word
    best = None
    for v, c in vocab.items():
        if abs(len(v) - len(word)) <= max_d:
            d = levenshtein(word, v)
            if d <= max_d and (best is None or (d, -c, v) < best):
                best = (d, -c, v)
    return best[2] if best else word

spelled = [' '.join(correct(w) for w in to_words(h)) for h in heard]
print(f'WER распознанного: {total_wer(said, heard):.3f} | после исправителя опечаток: {total_wer(said, spelled):.3f}')
for h, s in zip(heard, spelled):
    if h != s:
        print(f'  {h} → {s}')
```

Стало хуже: WER вырос с 0,306 до 0,333. Помог исправитель в одном месте: «коте» стало «коде», потому что слова «коте» в текстах курса нет. В остальном он вредит. Ошибки распознавания — чаще **настоящие слова**, и исправитель меняет одни слова на другие: «дети нации» → «сети найти», «бокс плот» → «пока по», «фью шот» → «всю от». «Случайный вес» он не тронул: «вес» в словаре есть. А правильные слова, которых в словаре нет, портит: «валидационная» и «хранить» встретились в текстах курса меньше двух раз и стали «валидационных» и «хранит». Инструмент нужно выбирать под вид ошибок. Для распознанной речи нужны другие средства: словарь терминов и склейка слов.
