## Зачем это нужно

Эта часть закрепляет NumPy, если основная работа уже выполнена. Две идеи пригодятся дальше в курсе:

- **оси** — посчитать статистику сразу для каждого столбца (сколько пропусков в каждом признаке, медиана каждого признака) одной строкой, без цикла;
- **broadcasting** — выполнить операцию между матрицей и вектором, например вычесть из каждого столбца его среднее. Именно так в модуле 5 будет работать стандартизация признаков перед обучением модели.

## Оси: какую ось «сворачиваем»

У матрицы две оси: ось 0 — строки, ось 1 — столбцы. Параметр `axis` в статистиках указывает, **вдоль какой оси идёт вычисление** — эта ось «схлопывается»:

- `axis=0` — сворачиваем строки: результат **для каждого столбца**;
- `axis=1` — сворачиваем столбцы: результат **для каждой строки**.

В нашей матрице `X` нельзя усреднять год, пробег и цену внутри одной строки — у них разные единицы. Поэтому для примера возьмём цены трёх автомобилей из двух условных источников: все ячейки в евро.

```python
two_sources = np.array([[5000., 5200.],
                        [8000., 8400.],
                        [10_000., 9800.]])
print('Матрица: автомобили × источники')
print(two_sources)
print('axis=0 — среднее по автомобилям для каждого источника:', two_sources.mean(axis=0))
print('axis=1 — среднее по источникам для каждого автомобиля:', two_sources.mean(axis=1))
```

Для матрицы признаков `axis=0` даёт сводку по каждому признаку — то, что в уроке 1.5 мы делали циклом:

```python
print('Пропусков по столбцам:   ', np.isnan(X).sum(axis=0))
print('Медианы признаков:       ', np.nanmedian(X, axis=0))
complete = np.isfinite(X).all(axis=1)       # строка пригодна, если все 4 значения конечны
print('Полных строк:', complete.sum(), 'из', len(X))
```

`.all(axis=1)` для каждой строки проверяет, что **все** её значения `True`; `.any(axis=1)` — что хотя бы одно.

## Broadcasting: операции над разными формами

Попарные операции требуют одинаковой формы — **или совместимой**. Правило NumPy (broadcasting, «растягивание»):

1. формы сравниваются **с конца** (справа налево);
2. размеры по оси совместимы, если они **равны** или один из них **равен 1**;
3. размер 1 «растягивается» до размера другого массива (данные при этом не копируются).

Число — это массив без осей, оно совместимо с чем угодно: `price + 100`. Матрица `(n, 4)` и вектор `(4,)` совместимы: вектор применяется к каждой строке.

```python
three_prices = np.array([5000., 8000., 10_000.])
column = three_prices.reshape(-1, 1)        # -1: «вычисли сам» → форма (3, 1)
print('Форма вектора:', three_prices.shape, '| форма столбца:', column.shape)
print('Столбец + вектор, форма:', (column + three_prices).shape)
print(column + three_prices)
print('Вектор после .T:', three_prices.T.shape, '| столбец после .T:', column.T.shape)
```

![Broadcasting](broadcast.svg "Столбец (3, 1) + вектор (3,) = матрица (3, 3)")

Почему `(3, 1) + (3,)` дало `(3, 3)`? Справа: 1 и 3 — совместимы, растягиваем до 3; слева у вектора оси нет — считается 1, растягиваем до 3. А `.T` у одномерного вектора ничего не меняет: у него одна ось, «поворачивать» нечего. Чтобы получить столбец, нужен `reshape(-1, 1)`.

## Практический пример: центрирование и стандартизация

Возьмём только полные строки и вычтем из каждого столбца его среднее, затем разделим на стандартное отклонение столбца:

$$
z_{ij} = \frac{x_{ij} - \bar{x}_j}{\sigma_j},
$$

где $\bar{x}_j$ и $\sigma_j$ — среднее и стандартное отклонение столбца $j$. Формы: `X_complete` — `(n, 4)`, средние — `(4,)`: broadcasting применит вектор к каждой строке.

```python
X_complete = X[complete]
col_mean = X_complete.mean(axis=0)
col_std = X_complete.std(axis=0)
Z = (X_complete - col_mean) / col_std
print('Форма Z:', Z.shape)
print('Средние столбцов Z:', Z.mean(axis=0).round(6))
print('Стандартные отклонения столбцов Z:', Z.std(axis=0).round(6))
print('Строк, где хоть один |z| > 3:', (np.abs(Z) > 3).any(axis=1).sum())
```

Теперь все признаки в «одних единицах» — числах стандартных отклонений от среднего. Это важно для моделей, которые сравнивают признаки по величине (модули 5–6). Числа, созданные `np.arange`, `np.linspace`, `np.zeros`, `np.ones`, — служебные массивы, а не новые наблюдения рынка.

## Типичные ошибки

:::mistake Перепутали ось
`X.mean(axis=1)` смешает год, пробег, объём и цену в одно число на строку — бессмыслица. Для сводки по признакам — `axis=0`.
:::

:::mistake Случайная огромная матрица
`price - price.reshape(-1, 1)` при 41 007 ценах создаст матрицу 41 007 × 41 007 (≈ 1,7 млрд чисел) — памяти не хватит. Если результат «неожиданно двумерный», проверьте формы операндов.
:::

:::mistake .T для вектора
`v.T` у вектора формы `(n,)` ничего не делает. Для столбца — `v.reshape(-1, 1)`.
:::

## Что запомнить

- `axis=0` — результат для каждого столбца, `axis=1` — для каждой строки.
- `.all(axis=1)` / `.any(axis=1)` — «все» / «хоть одно» условие в строке.
- Broadcasting: формы сравниваются с конца, размеры равны или один из них 1.
- `reshape(-1, 1)` делает из вектора столбец; `.T` вектор не меняет.
- Стандартизация `(X - X.mean(axis=0)) / X.std(axis=0)` — пример broadcasting, пригодится в модуле 5.
