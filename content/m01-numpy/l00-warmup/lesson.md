## Зачем это нужно

В модуле 1 мы будем анализировать данные с NumPy, но вокруг вычислений останется обычный Python: список названий столбцов, поиск номера столбца, красивый вывод результата, небольшие функции. Пять коротких задач освежат эти навыки, чтобы в уроках думать о данных, а не о синтаксисе.

Если Python для вас совсем новый, сначала пройдите необязательные уроки «Минимум Python» в модуле 0.

## Списки и позиции

Список хранит значения по порядку. Позиции считаются **с нуля**, отрицательные — с конца. Метод `.index(значение)` возвращает позицию значения, а `len(...)` — длину.

```python
header = ['Make', 'Model', 'Year', 'Style', 'Distance',
          'Engine_capacity(cm3)', 'Fuel_type', 'AutoTransmission', 'Price(euro)']
print(header[0], header[-1], len(header))
print('Номер столбца Year:', header.index('Year'))
```

## Генератор списка

Генератор списка `[выражение for x in коллекция]` строит новый список из старого за одну строку. Так мы найдём номера всех нужных столбцов сразу:

```python
numeric_names = ['Year', 'Distance', 'Engine_capacity(cm3)', 'Price(euro)']
numeric_columns = [header.index(name) for name in numeric_names]
print(numeric_columns)
```

## f-строки: вывод с единицами и форматом

В отчёте числа нужны с единицами и разумной точностью. f-строка подставляет значение в фигурных скобках, после двоеточия — формат: `.2f` — два знака после запятой, `,` — разделитель тысяч, `.1%` — доля в процентах.

```python
mean_price = 9727.1146
share = 12716 / 41007
print(f'Средняя цена: {mean_price:.2f} евро')
print(f'Средняя цена: {mean_price:,.0f} евро')
print(f'Доля дорогих: {share:.1%}')
```

## Что запомнить

- Позиции в списке — с нуля, `lst[-1]` — последний элемент, `lst.index(x)` — позиция значения.
- `[f(x) for x in items]` — короткий способ построить список.
- f-строка с форматом: `f'{x:.2f}'`, `f'{x:,.0f}'`, `f'{share:.1%}'`.
- Функция возвращает результат через `return`; без него вернётся `None`.
