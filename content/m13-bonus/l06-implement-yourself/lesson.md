## Зачем это нужно

До сих пор модели были готовыми: `fit`, `predict`, и всё работает. Написать модель самому — лучший способ понять, что именно она делает, почему ей нужна стандартизация, где она может застрять и почему иногда ошибается. В материалах курса есть папка `ml_numpy` с такими реализациями. В этом уроке мы напишем четыре из них и каждую сверим со scikit-learn: совпадение — проверка, что мы поняли алгоритм правильно.

## Устройство модели: fit и predict

У всех моделей scikit-learn одно устройство:

- **настройки** задаются при создании объекта: `KMeans(n_clusters=4)`;
- **`fit(X, y)`** учится по данным и сохраняет найденное в атрибутах с **подчёркиванием в конце**: `coef_`, `components_`, `cluster_centers_`. Возвращает сам объект — поэтому можно писать `model.fit(X, y).predict(X)`;
- **`predict(X)`** (или `transform`) пользуется только сохранённым и данных обучения больше не видит.

Простейшая модель с таким устройством — ориентир «всегда среднее» из урока 5.5:

```python
class MeanRegressor:
    def fit(self, X, y):
        self.mean_ = float(np.mean(y))        # найденное — в атрибуте с подчёркиванием
        return self                           # чтобы можно было писать .fit(...).predict(...)

    def predict(self, X):
        return np.full(len(X), self.mean_)    # только сохранённое, без данных обучения

price_train = X_train[:, 3]                     # цена — четвёртый столбец признаков
mine = MeanRegressor().fit(X_train, price_train).predict(X_test[:3])
dummy = DummyRegressor().fit(X_train, price_train).predict(X_test[:3])
print('своя модель:', mine.round(1), '| DummyRegressor:', dummy.round(1))
```

Подчёркивание — договорённость: атрибут появился после обучения. Пока модель не обучена, `mean_` нет, и обращение к нему — ошибка. Это лучше, чем молча ответить нулём.

## Логистическая регрессия: градиент log loss

Логистическую регрессию учат, уменьшая log loss (урок Б.1) градиентным спуском (урок 5.2). Градиент получается очень коротким: для коэффициентов — Xᵀ·(p − y) / n, для свободного члена — среднее (p − y). Здесь p — вероятности модели, а p − y — её ошибки. Сделаем несколько шагов вручную:

```python
w, b, lr = np.zeros(Xtr.shape[1]), 0.0, 0.5
for step in range(2001):
    p = 1 / (1 + np.exp(-(Xtr @ w + b)))
    if step in (0, 10, 100, 2000):
        pc = np.clip(p, 1e-15, 1 - 1e-15)                 # у крайних машин p бывает ровно 0 или 1
        loss = -np.mean(y_train * np.log(pc) + (1 - y_train) * np.log(1 - pc))
        print(f'шаг {step:4}: log loss {loss:.4f}, коэффициенты {w.round(3)}')
    w -= lr * Xtr.T @ (p - y_train) / len(y_train)
    b -= lr * np.mean(p - y_train)

sk = LogisticRegression(C=1e10).fit(Xtr, y_train)      # регуляризация практически выключена
print('scikit-learn:', sk.coef_[0].round(3))
```

На шаге 0 все коэффициенты нули, все вероятности 0,5, и log loss равен log 2 ≈ 0,693. Через 2000 шагов коэффициенты совпали с `LogisticRegression(C=1e10)`. По умолчанию scikit-learn немного прижимает коэффициенты к нулю — это регуляризация с силой 1 / C, и C = 1. С C = 10¹⁰ она практически выключена, поэтому сверяем так. Вероятности перед логарифмом обрезаем, как в задании урока Б.1. У машин с крайними значениями — например, ценой в сотни тысяч евро — модель уверена настолько, что p в компьютере равно ровно 1, и log(1 − p) не определён. Стандартизация здесь обязательна: с пробегом в километрах градиент был бы в тысячи раз больше по одной координате, и подобрать шаг `lr` было бы невозможно.

## PCA и k-means

Эти два алгоритма мы уже написали построчно в уроках Б.4 и Б.5. Осталось упаковать их в классы:

- **PCA**: `fit` запоминает среднее `mean_`, собственные векторы ковариационной матрицы по убыванию собственных чисел — `components_` (строками, как в sklearn) — и `explained_variance_ratio_`. `transform` вычитает среднее и умножает на компоненты: `(X - mean_) @ components_.T`;
- **k-means**: `fit` повторяет «назначить ближайшим — пересчитать центры» и запоминает `cluster_centers_`, `labels_` и `inertia_`. `predict` назначает новые объекты ближайшим центрам.

## Дерево: индекс Джини и лучший порог

Дерево решений (уроки 6.4–6.5) на каждом шаге ищет вопрос «признак ≤ порог», после которого классы в частях чище всего. Нечистоту части меряет **индекс Джини**: для двух классов 2·p·(1 − p), где p — доля класса 1. В чистой части он 0, при 50 на 50 — 0,5. Качество разбиения — средний Джини частей, взвешенный их размерами.

Перебирать все пороги по одному долго. Удобнее отсортировать объекты по признаку и сразу получить число единиц слева при любом пороге — накопленной суммой:

```python
rng = np.random.default_rng(0)
idx = rng.choice(len(X_train), 3000, replace=False)
xs_all, ys_all = X_train[idx, 3], y_train[idx]          # цена и коробка у 3000 машин
order = np.argsort(xs_all, kind='stable')
xs, ys = xs_all[order], ys_all[order]
n = len(ys)
left_n = np.arange(1, n)                                 # слева 1, 2, …, n − 1 объектов
left_pos = np.cumsum(ys)[:-1]                            # из них автоматов
pl, pr = left_pos / left_n, (ys.sum() - left_pos) / (n - left_n)
gini_split = (left_n * 2 * pl * (1 - pl) + (n - left_n) * 2 * pr * (1 - pr)) / n
gini_split[xs[1:] == xs[:-1]] = np.inf                   # между равными значениями порог не поставить
i = int(np.argmin(gini_split))
p_all = ys.mean()
print(f'Джини всех машин {2 * p_all * (1 - p_all):.3f}; лучший порог по цене {(xs[i] + xs[i + 1]) / 2:.1f}, Джини после разбиения {gini_split[i]:.3f}')
tree = DecisionTreeClassifier(max_depth=1).fit(xs_all.reshape(-1, 1), ys_all)
print('scikit-learn: порог', tree.tree_.threshold[0])
```

Порог ставят посередине между соседними различными значениями — так же делает scikit-learn, и пороги совпали: 8299,5 евро. Джини упал с 0,498 до 0,347: среди машин дешевле этой цены в основном механика, дороже — автоматы. Дальше дерево **рекурсивно** делает то же самое в каждой части, пока не дойдёт до нужной глубины или до чистой части. В листе отвечает самым частым классом.

## Типичные ошибки

:::mistake Сверять свою логистическую регрессию с моделью по умолчанию
У `LogisticRegression()` по умолчанию регуляризация (C = 1), и коэффициенты немного меньше. Для сверки берите очень большое C, например `C=1e10`, или добавляйте тот же штраф в свой градиент.
:::

:::mistake Забыть return self в fit
Без него `model.fit(X, y).predict(X)` упадёт: `fit` вернёт None. Все модели scikit-learn возвращают из `fit` сам объект.
:::

:::mistake Сравнивать компоненты PCA со знаком
Собственный вектор определён с точностью до знака: свои и sklearn-компоненты сравнивают по модулю.
:::

## Что запомнить

- Устройство модели: настройки в `__init__`, обучение в `fit` с атрибутами вида `coef_` и `return self`, ответы в `predict` только по сохранённому.
- Логистическую регрессию учат градиентным спуском по log loss: градиент по коэффициентам — Xᵀ·(p − y) / n.
- PCA — собственные векторы ковариационной матрицы, k-means — назначение и пересчёт центров; обёрнутые в классы, они совпадают со scikit-learn.
- Дерево выбирает порог с наименьшим взвешенным индексом Джини частей, порог — посередине между соседними значениями; дальше — рекурсия по частям.
- Свою реализацию проверяют сверкой с готовой моделью на тех же данных и с теми же настройками.
