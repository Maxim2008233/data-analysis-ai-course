## Зачем это нужно

В соревновании курса одна и та же просьба уходит модели 786 раз — меняются только вопрос и варианты ответа. Такой промпт — **шаблон** с местами для подстановки. Его пишут один раз, проверяют и потом заполняют данными.

Второй приём — показать модели несколько **решённых примеров** того же вида. Модель видит образец и отвечает так же, в том же формате. Это **few-shot** — промпт с несколькими примерами. Промпт без примеров называют **zero-shot**, как CLIP в уроке 9.7, которому хватало названий классов.

## Шаблон базового решения

Вот промпт, который собирает базовое решение соревнования:

```python
def qa_message_template(question, answers):
    msg = question
    msg += ' варианты ответа: '
    msg += answers
    msg += ' ответ должен быть номером варианта, считая от 0 '
    return msg

print(qa_message_template(qa.loc[1, 'вопрос'], qa.loc[1, 'варианты']))
```

Всё склеено в одну строку, а варианты вставлены как есть — JSON-строкой. Чтобы ответить «2», модель должна сама сосчитать позиции в списке, причём с нуля. А формат ответа описан словами, и модель может ответить целым предложением.

## Шаблон с местами для подстановки

Запишем шаблон один раз, с именованными местами `{question}` и `{options}`, а варианты пронумеруем:

```python
TEMPLATE = """Вопрос: {question}
Варианты ответа:
{options}
Ответ:"""

def format_options(options):
    return '\n'.join(f'{i}) {o}' for i, o in enumerate(options))

row = qa.loc[1]
print(TEMPLATE.format(question=row['вопрос'], options=format_options(row['options'])))
```

`str.format` подставляет значения на места с теми же именами — как f-строка, только шаблон хранится отдельно и заполняется потом. Теперь номер стоит рядом с каждым вариантом: считать модели не нужно. Промпт кончается словом «Ответ:», и самое естественное продолжение — цифра.

## Фигурные скобки в шаблоне

Для `str.format` всё в фигурных скобках — место для подстановки. Если попросить в шаблоне ответ в формате JSON, скобки примера `format` примет за места подстановки:

```python expect-error
bad = 'Ответь в формате {"answer": номер}.\n' + TEMPLATE
bad.format(question='Вопрос', options='0) да\n1) нет')
```

Чтобы вписать в текст саму скобку, её удваивают: `{{` превращается в `{`, а `}}` — в `}`. Шаблон `'Ответь в формате {{"answer": номер}}.'` после `format` даст ровно `Ответь в формате {"answer": номер}.` — это задание урока.

## Few-shot: решённые примеры

Перед вопросом поставим два решённых вопроса той же темы, с ответами:

```python
def solved(r):
    return TEMPLATE.format(question=r['вопрос'], options=format_options(r['options'])) + f" {r['ответ']}"

i = 1
same = qa[(qa['категория'] == qa.loc[i, 'категория']) & (qa.index != i)]    # та же тема, кроме самого вопроса
blocks = [solved(r) for _, r in same.head(2).iterrows()]
blocks.append(TEMPLATE.format(question=qa.loc[i, 'вопрос'], options=format_options(qa.loc[i, 'options'])))
prompt = '\n\n'.join(blocks)
print(prompt)
print('Токенов:', count_tokens(prompt), 'вместо', count_tokens(blocks[-1]))
```

Модель видит образец: вопрос, пронумерованные варианты, «Ответ:» и одна цифра. Продолжая текст, она отвечает так же. Примеры показывают формат надёжнее, чем его словесное описание. Но они и дороже: этот промпт — 78 токенов вместо 23.

## Примеры как история диалога

Чат-модели примеры можно передать как прошлые сообщения диалога. Вопрос — с ролью `user`, ответ — с ролью `assistant` (урок 10.3):

```python
SYSTEM = 'Ты решаешь тест. Отвечай одной цифрой — номером правильного варианта.'
messages = [{'role': 'system', 'content': SYSTEM}]
for _, r in same.head(2).iterrows():
    messages.append({'role': 'user', 'content': TEMPLATE.format(question=r['вопрос'], options=format_options(r['options']))})
    messages.append({'role': 'assistant', 'content': str(r['ответ'])})
messages.append({'role': 'user', 'content': blocks[-1]})
for m in messages:
    print(f"{m['role']:9} | {m['content'][:60]!r}")
```

Модель принимает примеры за свои прошлые ответы и продолжает в том же духе — одной цифрой.

## Сколько стоят примеры

Каждый пример уходит в каждом запросе. Сравним все 87 вопросов без примеров и с тремя примерами:

```python
zero = sum(count_tokens(TEMPLATE.format(question=r['вопрос'], options=format_options(r['options'])))
           for _, r in qa.iterrows())
three = 0
for i in qa.index:
    shots = [solved(r) for _, r in qa.drop(index=i).head(3).iterrows()]    # три примера, кроме самого вопроса
    question = TEMPLATE.format(question=qa.loc[i, 'вопрос'], options=format_options(qa.loc[i, 'options']))
    three += count_tokens('\n\n'.join(shots + [question]))
print('без примеров:', zero, '| с тремя примерами:', three, '| в', round(three / zero, 1), 'раза больше')
```

Три примера увеличивают расход токенов в 3,6 раза: 8872 токена вместо 2495. Для 786 вопросов теста разница та же. Сколько примеров ставить, решают проверкой: помогают ли они настолько, чтобы окупить токены (урок 10.8).

## Как выбирать примеры

- **Не брать сам вопрос.** Если проверять промпт на вопросах с известными ответами, вопрос среди примеров — утечка ответа (урок 5.4): модель просто увидит правильный ответ в промпте.
- **Брать похожие.** Примеры той же темы показывают, как в ней устроены вопросы.
- **Следить за ответами.** Модели склонны повторять ответ, который чаще встречался в примерах и стоял в последнем примере. Это описано в исследовании Zhao и соавторов 2021 года. Если во всех примерах ответ 2, модель охотнее ответит 2.

На данных курса это видно сразу. В ноутбуке базового решения GigaChat ошибся на вопросе 12 — «Какова координата точки, симметричной (2, 3) относительно оси Y?»: ответил 2, а правильный — 0. У двух первых вопросов той же темы правильный ответ — тоже 2. По наблюдению Zhao и соавторов, такие примеры только подталкивали бы модель к ответу 2. Как выбрать примеры с разными ответами — задание со звёздочкой.

## Типичные ошибки

:::mistake Одиночные фигурные скобки в шаблоне
`'{"answer": 0}'` внутри шаблона ломает `format`: скобки он принимает за место подстановки. В тексте шаблона скобки удваивают: `{{"answer": 0}}`.
:::

:::mistake Сам вопрос среди примеров
Модель увидит в промпте правильный ответ, и проверка покажет завышенное качество. Вопрос исключают из примеров: `qa.index != i`.
:::

:::mistake Примеры в другом формате, чем вопрос
Модель повторяет формат примеров. Если в примерах варианты пронумерованы, а в вопросе вставлены JSON-строкой, модель запутается. Все блоки собирают одним шаблоном.
:::

## Что запомнить

- Промпт для многих запросов — шаблон с местами `{имя}`, который заполняют через `format`. Фигурные скобки в его тексте удваивают.
- Варианты ответа лучше пронумеровать в промпте, а не вставлять JSON-строкой.
- Few-shot — решённые примеры перед вопросом. Их ставят текстом или как историю диалога: вопрос — `user`, ответ — `assistant`.
- Примеры стоят токенов в каждом запросе. Их берут похожими, без самого вопроса и с разными ответами.
