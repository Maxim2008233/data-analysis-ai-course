## Зачем это нужно

Языковая модель получает на вход текст и возвращает текст. Всё, что между ними, — обычное программирование со строками:

- **промпт** собирают из данных — вопроса, вариантов ответа, примеров;
- **ответ** модели разбирают — находят в нём номер варианта, число, словарь.

Данные модуля — тест из соревнования курса: 87 вопросов с вариантами ответа и номером правильного (`qa_train.csv`).

## Вопрос и варианты

```python
print(qa.shape)
print(qa.head(3))
row = qa.iloc[5]
options = json.loads(row['варианты'])      # строка в формате JSON → список Python
print(row['вопрос'])
for i, option in enumerate(options):
    print(f'{i}) {option}')
print('Правильный:', options[row['ответ']])
```

Варианты ответа хранятся строкой в формате **JSON** — так записывают списки и словари текстом. `json.loads` превращает такую строку обратно в список. Номер правильного варианта считается с нуля, как индекс списка: в вопросе про песто правильный вариант 3 — «Кедровый орех».

## Когда это не JSON

```python
def parse_options(s):
    try:
        return json.loads(s)
    except json.JSONDecodeError:                 # не JSON — пробуем разобрать как список Python
        with warnings.catch_warnings():
            warnings.simplefilter('ignore', SyntaxWarning)
            return ast.literal_eval(s)

bad = [s for s in qa['варианты'] if not s.startswith('["')]
print('Не JSON:', bad)
qa['options'] = qa['варианты'].apply(parse_options)
print('Вариантов в вопросе:', qa['options'].str.len().value_counts().to_dict())
```

В трёх строках варианты записаны в одинарных кавычках: `['35', '28', '42', '49']`. Это список Python, но не JSON — `json.loads` на нём падает. Выручает `ast.literal_eval`: он безопасно читает записанные текстом значения Python — списки, строки, числа — и не выполняет код. `try` / `except` пробует первый способ, а при ошибке переходит ко второму.

И сюрприз: в описании задачи сказано, что вариантов «ровно четыре». На деле у шести вопросов их десять, а у двух — семь. Поэтому номер правильного ответа бывает и 5, и 7. Программа не должна полагаться на «всегда четыре».

## Промпт из шаблона

Базовое решение соревнования собирает промпт так:

```python
def qa_message_template(question, answers):
    msg = question
    msg += ' варианты ответа: '
    msg += answers
    msg += ' ответ должен быть номером варианта, считая от 0 '
    return msg

print(qa_message_template(qa.loc[0, 'вопрос'], qa.loc[0, 'варианты']))
```

Промпт — это просто строка, собранная из кусков: текст вопроса, варианты ответа и инструкция. То же самое короче записывается f-строкой: `f"{question} варианты ответа: {answers} ..."`. В следующих уроках мы будем улучшать именно эту строку.

## Число в ответе

Модель отвечает текстом, а нужен номер. Базовое решение берёт первое число в ответе:

```python
answers = ['Правильный ответ: 2', 'Вариант 0 — 1662 год', 'В 1662 году — вариант 0', 'Не знаю']
for text in answers:
    numbers = re.findall(r'\d+', text)          # все группы цифр подряд
    print(f'{text!r:30} → {numbers} → первое: {numbers[0] if numbers else None}')
```

`re.findall(r'\d+', текст)` находит все группы цифр: `\d` — цифра, `+` — одна или больше подряд. Первое число — не всегда номер варианта: в третьем ответе это год. Как часто так ломалось настоящее решение — в уроке 10.5.
