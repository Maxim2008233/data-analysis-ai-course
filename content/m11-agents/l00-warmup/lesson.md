## Зачем это нужно

У большой языковой модели три ограничения (лекция, слайд 7):

- она обучена на данных, собранных год или больше назад, — свежего не знает;
- обучена на открытых данных — закрытых документов компании не видела;
- она только пишет текст — действовать во внешнем мире не может.

В модуле 11 мы будем обходить эти ограничения. **RAG** находит нужные документы и подкладывает их модели в промпт. **Агент** вызывает инструменты — поиск, календарь, калькулятор. Обоим нужны вещи, знакомые по прошлым модулям:

- текст превращают в вектор, а похожие тексты дают похожие векторы (модуль 9);
- «похожесть» меряют косинусным сходством и берут k самых похожих;
- инструменты получают аргументы и отдают результаты в формате JSON (модуль 10).

## База знаний: разделы уроков курса

Искать будем по самому курсу. Каждый раздел каждого урока модулей 0–10 — отдельный документ: номер урока, название, заголовок раздела и текст без кода и формул.

```python
print('Разделов:', len(docs))
print(json.dumps(docs[100], ensure_ascii=False, indent=1))
by_module = Counter(d['module'] for d in docs)
print('Разделов по модулям:', sorted(by_module.items()))
print('Уроков:', len({d['lesson'] for d in docs}))
```

Разделы небольшие: в половине из них меньше 500 символов. В RAG документы специально режут на такие куски — **чанки**. Найденный кусок целиком помещается в промпт, и в нём меньше постороннего, чем в целом уроке.

## Векторы и косинусное сходство

Повторим урок 9.2 на настоящих векторах модели CLIP: у каждого из 349 названий классов картинок — вектор из 512 чисел.

```python
def cosine(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

i, j, k = names.index('chair'), names.index('wheelchair'), names.index('dolphin')
print(f"chair — wheelchair: {cosine(vecs[i], vecs[j]):.3f}")
print(f"chair — dolphin:    {cosine(vecs[i], vecs[k]):.3f}")
print('Длины векторов: от', round(float(np.linalg.norm(vecs, axis=1).min()), 4),
      'до', round(float(np.linalg.norm(vecs, axis=1).max()), 4))
```

Косинус — это скалярное произведение, делённое на длины векторов. Векторы CLIP уже нормированы на длину 1, поэтому для них косинус равен просто `a @ b`. Так же будет и в поиске по документам: векторы документов нормируют заранее, а потом сравнивают одним умножением матрицы на вектор.

## Ближайшие k

```python
scores = vecs @ vecs[names.index('dolphin')]       # сходство со всеми 349 векторами сразу
top = np.argsort(-scores)[:4]                      # по убыванию: минус перед scores
for t in top:
    print(f'{names[t]:20} {scores[t]:.3f}')
```

`np.argsort` сортирует по возрастанию и возвращает номера, а не значения. Минус перед `scores` разворачивает порядок: первыми идут самые похожие. Первое место у самого «dolphin» — сходство вектора с собой равно 1. Ближайшие соседи — «bottlenose dolphin», «horse», «elephant». CLIP училась на подписях к картинкам, и для неё дельфин рядом с другими крупными животными на фотографиях.

## JSON: вызов инструмента

Агент просит программу вызвать инструмент примерно так: имя инструмента и аргументы. Передают это строкой в формате JSON:

```python
call = {'name': 'search_course', 'arguments': {'query': 'переобучение', 'k': 3}}
text = json.dumps(call, ensure_ascii=False)        # словарь → строка JSON
print(text)
back = json.loads(text)                            # строка JSON → словарь
print(back['name'], back['arguments']['k'] + 1)
print(json.dumps({'query': 'переобучение'}))       # без ensure_ascii=False русские буквы — коды \u...
```

`json.dumps` превращает словарь в строку, `json.loads` — обратно. С `ensure_ascii=False` русские буквы остаются буквами, без него превращаются в коды вида `п`. Это тоже правильный JSON, но читать его неудобно. Модель пишет JSON сама, и он бывает сломан: одинарные кавычки, лишняя запятая, текст вокруг. Поэтому разбор всегда идёт в `try` / `except json.JSONDecodeError`, как в уроке 10.5.
