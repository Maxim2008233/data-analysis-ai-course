## Зачем это нужно

За модуль мы собрали все детали помощника по курсу:

- поиск по разделам уроков, устойчивый к формам слов (уроки 11.1–11.2);
- порог «не знаю» и ответ со ссылкой на урок (урок 11.3);
- фильтр подозрительных просьб (урок 11.6);
- инструмент, которым может пользоваться агент (уроки 11.4–11.5).

Осталось соединить их и честно проверить, что получилось.

Отвечать будет не языковая модель — без ключа в браузере её нет. Отвечать будет **извлекающий** ответчик: он не сочиняет текст, а выбирает из найденных разделов предложение, которое больше всего похоже на вопрос, и ставит ссылку на его урок. Такой ответчик никогда не выдумывает фактов — он цитирует курс. Зато он не умеет пересказывать своими словами и соединять несколько разделов. Устройство помощника от этого не зависит: в Colab функцию ответа заменяют вызовом GigaChat с промптом из урока 11.3, а поиск, порог, фильтр и проверки остаются теми же.

## С чего начинает помощник

Первый шаг каждого ответа — поиск из урока 11.3. Вот что он находит для вопроса из половины `test`:

```python
def search(question, k=3):
    scores = (X @ vectorizer.transform([question]).T).toarray().ravel()
    top = np.argsort(-scores, kind='stable')[:k]
    return [(float(scores[i]), docs[i]) for i in top]

for score, d in search('Что такое случайный лес?'):
    print(f"{score:.3f} [{d['lesson']}] {d['section']}: {d['text'][:110]}…")
```

Раздел нашёлся, но целиком он слишком длинный для ответа: нужен один кусок, который отвечает на вопрос. Этим займутся шаги 1 и 2.
