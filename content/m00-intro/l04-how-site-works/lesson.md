## Зачем это нужно

Пять минут на знакомство с инструментами сэкономят часы. Здесь всё работает прямо в браузере: Python, библиотеки для анализа данных, проверка заданий. Ниже — короткая инструкция и по одному заданию каждого типа, чтобы попробовать.

## Ячейки кода: In и Out

Код в уроках оформлен как в рабочей тетради аналитика (Jupyter): **In [n]** — ячейка с кодом, **Out [n]** — результат под ней.

- Нажмите **«Выполнить»** или **Ctrl+Enter** (на Mac — **Cmd+Enter**). Первый запуск загружает Python — 10–30 секунд, дальше всё берётся из кэша браузера.
- Код можно **менять** и запускать снова. Кнопка «исходный код» вернёт исходный вариант.
- Ячейки урока **связаны**, как в тетради: переменная из первого примера доступна во втором. Если запустить второй пример раньше первого, первый выполнится автоматически.
- Если последняя строка ячейки — выражение, его значение выводится автоматически (таблицы — красиво, как в Jupyter).

```python
price = 7750
year = 2011
print('Цена:', price, 'евро')
price * 2
```

```python
# этот пример использует переменные из предыдущего
age = 2021 - year
print(f'Машине {age} лет, цена за год возраста ≈ {price / age:.0f} евро')
```

## Графики выводятся под кодом

```python
import matplotlib.pyplot as plt

fuel = ['Бензин', 'Дизель', 'Гибрид', 'Газ']
counts = [15000, 17000, 2500, 1200]
fig, ax = plt.subplots(figsize=(6, 3))
ax.bar(fuel, counts, color='#3d5bd9')
ax.set_title('Объявлений по типу топлива (пример)')
ax.set_ylabel('Число объявлений')
plt.show()
```

## Ошибки объясняются по-русски

Ошибаться — нормально. Под кодом появится объяснение: что произошло, в какой строке и что проверить. Исходный текст ошибки Python (traceback) открывается кнопкой. Запустите пример с опечаткой:

```python expect-error
mileage = 195000
print(milage)
```

## Задания и проверка

Задания в конце урока идут по возрастанию сложности: **разминка** → **основное** → **★ со звёздочкой** (необязательное). Типы заданий:

| Тип | Что нужно сделать |
|---|---|
| Код | Написать код; переменные с нужными именами проверяют тесты |
| Квиз | Выбрать один или несколько ответов |
| Найди ошибку | Исправить готовый код, в котором есть ошибка |
| Предскажи вывод | Ответить, что выведет код, не запуская его |
| График | Построить график; тесты проверяют тип, число столбцов, подписи |

Как устроена проверка:

- **«Выполнить»** просто запускает ваш код, **«Проверить»** запускает его и затем **тесты** задания.
- Сообщение подскажет, **что именно не так**: «Переменная `clean` содержит 41 007 строк, а должно остаться меньше — вы удалили повторы?».
- Чтобы число нельзя было просто вписать, тесты часто запускают ваш код ещё раз **на другой части данных**.
- Если код работает дольше 20 секунд (например, бесконечный цикл), он будет остановлен, и Python перезапустится.
- Код **сохраняется автоматически**; «Сбросить к исходному» вернёт заготовку.

## Подсказки, решение, «Вспомним» и справочник

- У каждого задания **три подсказки**: направление мысли → конкретный инструмент → почти готовое решение. Открывайте по одной.
- Кнопка **«Показать решение»** появится после всех подсказок или после трёх неудачных проверок. Решение — с построчным разбором. Использование подсказок отмечается в профиле, но баллы не снимаются.
- Карточки **«Вспомним»** у задания напоминают понятия из прошлых уроков — с примером и ссылкой.
- Кнопка **«Справочник»** в правом нижнем углу урока открывает поиск по терминам и функциям.

## Прогресс

Без входа прогресс и код хранятся **в этом браузере**. После входа — в облаке, и их видно на любом устройстве; решённые без входа задачи переносятся в аккаунт. В профиле можно экспортировать прогресс в файл и импортировать его обратно.
