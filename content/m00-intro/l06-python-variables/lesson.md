## Зачем это нужно

Аналитик всё время что-то запоминает и пересчитывает: число записей, среднюю цену, долю дорогих машин. Чтобы не держать числа в голове, их сохраняют в **переменных**. А чтобы результат прочитал заказчик, его выводят понятным текстом с единицами и разумной точностью — для этого есть **f-строки**.

Этот урок необязательный: если тест 0.5 решён, его можно пропустить.

## Переменная — имя для значения

Переменная создаётся присваиванием `имя = значение`. Справа может быть число, текст или целое выражение — Python сначала вычислит правую часть, потом свяжет результат с именем.

```python
price = 7750          # цена, евро
year = 2011           # год выпуска
make = 'Toyota'       # марка — строка в кавычках
age = 2021 - year     # значение можно вычислить
print(make, year, price, age)
```

Правила имён: латинские буквы, цифры и `_`, не начинаются с цифры, регистр важен (`price` и `Price` — разные переменные). Называйте по смыслу: `mean_price` понятнее, чем `x`.

Значение переменной можно заменить: `price = 8000` — старое значение забыто. Можно и пересчитать через само себя: `price = price * 1.1`.

## Основные типы

У каждого значения есть **тип**:

| Тип | Что хранит | Пример |
|---|---|---|
| `int` | целое число | `2011`, `41007` |
| `float` | дробное число | `7750.0`, `0.31` |
| `str` | текст (строка) | `'Toyota'` |
| `bool` | логическое значение | `True`, `False` |

Узнать тип — `type(x)`. Перевести из одного в другой — `int(...)`, `float(...)`, `str(...)`. Это нужно, например, когда число прочитано из файла как текст:

```python
price_text = '7750.0'          # так значения выглядят в CSV
print(type(price_text))
price = float(price_text)       # строка → дробное число
print(type(price), price * 2)
print(int(price), str(year) + ' год')
```

## Арифметика

| Операция | Смысл | Пример | Результат |
|---|---|---|---|
| `+ - *` | сложение, вычитание, умножение | `7750 * 2` | `15500` |
| `/` | деление (всегда `float`) | `41007 / 4` | `10251.75` |
| `//` | целочисленное деление | `41007 // 4` | `10251` |
| `%` | остаток от деления | `41007 % 4` | `3` |
| `**` | степень | `1.1 ** 2` | `1.21` |

Порядок действий — как в математике; сомневаетесь — ставьте скобки. Доля и проценты:

$$
\text{доля} = \frac{12\,716}{41\,007} \approx 0.31, \qquad \text{процент} = 0.31 \cdot 100 = 31\,\%.
$$

## f-строки: вывод с форматом

`print(a, b)` выводит значения через пробел. Чтобы собрать аккуратную фразу, используют **f-строку**: буква `f` перед кавычками, а в фигурных скобках — любое выражение. После двоеточия можно указать **формат**:

- `{x:.2f}` — два знака после запятой;
- `{x:,.0f}` — без дробной части, с разделителем тысяч (запятая);
- `{share:.1%}` — доля как процент с одним знаком.

```python
mean_price = 9727.11458
count, total = 12716, 41007
share = count / total
print(f'Средняя цена: {mean_price:.2f} евро')
print(f'Средняя цена: {mean_price:,.0f} евро')
print(f'Дорогих объявлений: {count} из {total} ({share:.1%})')
print(f'Через год машине будет {age + 1} лет')
```

## Типичные ошибки

:::mistake Сложение строки и числа
`'Цена: ' + 7750` вызывает `TypeError: can only concatenate str (not "int") to str`. Используйте f-строку: `f'Цена: {price}'` или `str(price)`.
:::

:::mistake Число в кавычках
`'7750' * 2` даёт `'77507750'` — строка повторилась. Переведите в число: `float('7750') * 2`.
:::

:::mistake Опечатка в имени
`print(pirce)` → `NameError: name 'pirce' is not defined`. Python различает регистр и каждую букву.
:::

:::mistake / вместо //
`41007 / 4` даёт `10251.75`. Если нужно целое число частей — `//`, остаток — `%`.
:::

```quiz
- q: "Какой тип у значения `7750.0`?"
  options:
    - "`int`"

  answer: 1
  explain: Точка делает число дробным — тип float.
- q: "Что выведет `print(f'{0.31009:.1%}')`?"
  options:
    - "0.3"
    - "31.0%"
    - "31%"
  answer: 1
  explain: Формат `%` умножает на 100 и добавляет знак процента; `.1` — один знак после запятой.
- q: "Чему равно `17 // 5` и `17 % 5`?"
  options:
    - "3 и 2"
    - "3.4 и 2"
    - "2 и 3"
  answer: 0
  explain: 17 = 3 · 5 + 2.
```

## Что запомнить

- `имя = значение` создаёт переменную; имена — по смыслу, регистр важен.
- Основные типы: `int`, `float`, `str`, `bool`; перевод — `int()`, `float()`, `str()`.
- `/` даёт дробное, `//` — целую часть, `%` — остаток, `**` — степень.
- f-строка: `f'{x:.2f}'`, `f'{x:,.0f}'`, `f'{share:.1%}'`.
