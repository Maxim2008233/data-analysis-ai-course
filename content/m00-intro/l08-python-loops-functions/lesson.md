## Зачем это нужно

Три последних кирпичика: **условие** (сделать что-то, только если выполняется правило — «если цена выше 10 000, отметить как дорогую»), **цикл** (повторить действие для каждого элемента — «для каждого столбца посчитать пропуски») и **функция** (дать имя куску вычислений, чтобы применять его много раз — «доля дорогих машин в любой группе»).

В анализе данных циклы используют для повторения **опытов** и обхода **групп**, а не для поэлементной арифметики — её быстрее делает NumPy. Но понимать циклы нужно обязательно.

## Условие if / elif / else

После `if` пишется условие, после двоеточия — блок кода **с отступом 4 пробела**. `elif` проверяется, только если предыдущие условия ложны; `else` — если не подошло ни одно.

```python
price = 12500
if price < 5000:
    label = 'дешёвая'
elif price < 15000:
    label = 'средняя'
else:
    label = 'дорогая'
print(price, '→', label)

year, distance = 1998, 1
if distance < 1000 and year < 2020:
    print('Подозрительно малый пробег — проверить запись')
```

Сравнения: `==` (равно — два знака!), `!=`, `<`, `>`, `<=`, `>=`. Связки для одиночных значений: `and`, `or`, `not`. Для массивов NumPy вместо них будут `&`, `|`, `~` (урок 1.5).

## Цикл for

`for элемент in коллекция:` выполняет блок для каждого элемента. Полезные помощники:

- `range(n)` — числа 0, 1, …, n − 1;
- `enumerate(lst)` — пары (номер, элемент);
- `zip(a, b)` — пары элементов двух списков с одинаковыми номерами.

```python
prices = [7750, 8550, 2200, 6550, 4100, 12500]
total = 0
n_expensive = 0
for p in prices:
    total += p                       # то же, что total = total + p
    if p > 7000:
        n_expensive += 1
print('Средняя:', total / len(prices), '| дороже 7000:', n_expensive)

names = ['Year', 'Distance', 'Price']
missing = [0, 0, 205]
for i, (name, m) in enumerate(zip(names, missing)):
    print(i, name, m)
```

Ещё короче — **генератор списка**: `[выражение for x in коллекция if условие]`:

```python
litres = [cm3 / 1000 for cm3 in [1800, 1500, 1400]]
cheap = [p for p in prices if p < 5000]
print(litres, cheap)
```

## Функции

Функция объявляется словом `def`, принимает аргументы и **возвращает** результат через `return`. Без `return` функция возвращает `None` — частая причина ошибок.

```python
def share(count, total):
    """Доля count от total, округлённая до 3 знаков; 0.0, если total = 0."""
    if total == 0:
        return 0.0
    return round(count / total, 3)

def describe(values):
    return {'n': len(values), 'min': min(values), 'max': max(values), 'mean': sum(values) / len(values)}

print(share(12716, 41007), share(5, 0))
print(describe(prices))
```

Строка в тройных кавычках сразу после `def` — **документация** функции: что она делает и что возвращает. Функцию можно вызывать сколько угодно раз с разными аргументами — это и есть её смысл.

## Типичные ошибки

:::mistake Нет отступа или двоеточия
После `if`, `for`, `def` нужно двоеточие, а тело блока — с одинаковым отступом. Иначе — `SyntaxError: expected ':'` или `IndentationError`.
:::

:::mistake = вместо ==
`if price = 5000:` — синтаксическая ошибка. Для сравнения — `==`.
:::

:::mistake print вместо return
Функция, которая только печатает результат, возвращает `None`: `x = f(...)` окажется пустым. Для результата — `return`.
:::

:::mistake Счётчик внутри цикла
Если написать `total = 0` **внутри** цикла, сумма будет обнуляться на каждом шаге. Начальное значение задают до цикла.
:::

## Мини-квиз

```quiz
- q: "Что выведет код: `x = 7` → `if x > 10: print('A')` → `elif x > 5: print('B')` → `else: print('C')`?"
  options:
    - "A"
    - "B"
    - "B и C"
  answer: 1
  explain: Выполняется первый блок с истинным условием, остальные пропускаются.
- q: "Сколько раз выполнится тело цикла `for i in range(3):`?"
  options:
    - "2"
    - "3"
    - "4"
  answer: 1
  explain: range(3) — это 0, 1, 2.
- q: "Что вернёт функция `def f(x): print(x * 2)` при вызове `y = f(5)`? Чему равно `y`?"
  options:
    - "10"
    - "None"
    - "5"
  answer: 1
  explain: Функция печатает 10, но ничего не возвращает — значит, возвращает None.
```

## Что запомнить

- `if / elif / else` — выполнение по условию; тело блока — с отступом 4 пробела, после условия — двоеточие.
- `for x in коллекция:` повторяет блок; `range`, `enumerate`, `zip` — частые помощники.
- `[f(x) for x in items if условие]` — генератор списка.
- `def имя(аргументы):` + `return` — функция; без `return` она возвращает `None`.
