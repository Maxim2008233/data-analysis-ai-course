## Зачем это нужно

Одна переменная — одно значение. Но в анализе данных значений тысячи: цены всех объявлений, названия столбцов, число машин по маркам. Для этого в Python есть коллекции. **Список** хранит значения по порядку (как столбец таблицы), **словарь** — пары «название → значение» (как карточка одного объявления). Массивы NumPy и таблицы Pandas, с которыми мы будем работать дальше, — «прокачанные» версии этих идей.

## Список: значения по порядку

Список записывают в квадратных скобках. К элементу обращаются по **номеру позиции — с нуля**; отрицательные номера считают с конца.

```python
prices = [7750, 8550, 2200, 6550, 4100]
print('Первая:', prices[0], '| последняя:', prices[-1], '| всего:', len(prices))
print('Срез первых трёх:', prices[:3])
prices.append(9550)          # добавить в конец
prices[2] = 2300             # заменить элемент
print(prices)
print('Есть ли цена 4100?', 4100 in prices)
print('Сумма, минимум, максимум:', sum(prices), min(prices), max(prices))
```

Срез `a[start:stop]` берёт элементы с позиции `start` до `stop` **не включительно**: `prices[:3]` — позиции 0, 1, 2. Метод `.index(x)` возвращает позицию значения — так в модуле 1 мы найдём номер нужного столбца по заголовку файла.

Важная особенность: `*` и `+` у списков означают **повторение и склейку**, а не арифметику: `[1, 2] * 2` — это `[1, 2, 1, 2]`. Поэлементную арифметику дают массивы NumPy (урок 1.4).

## Словарь: значения по названиям

Словарь — набор пар **ключ: значение** в фигурных скобках. Обращение — по ключу, а не по номеру:

```python
car = {'make': 'Toyota', 'model': 'Prius', 'year': 2011, 'price': 7750}
print(car['make'], car['price'])
car['distance'] = 195000          # добавить новую пару
car['price'] = 7500               # изменить значение
print(car)
print('Ключи:', list(car.keys()))
print('Цвет:', car.get('color', 'не указан'))   # безопасное чтение
for key, value in car.items():
    print(f'{key:>9}: {value}')
```

`car['color']` вызвал бы ошибку `KeyError`, если такого ключа нет; метод `.get(ключ, по_умолчанию)` вернёт запасное значение.

## Список словарей и словарь со счётчиками

Две частые конструкции в анализе данных:

```python
cars = [
    {'make': 'Toyota', 'price': 7750},
    {'make': 'Renault', 'price': 8550},
    {'make': 'Toyota', 'price': 6200},
]
counts = {}
for c in cars:
    counts[c['make']] = counts.get(c['make'], 0) + 1
print('Объявлений по маркам:', counts)
print('Цены всех машин:', [c['price'] for c in cars])
```

Список словарей — это по сути таблица (каждый словарь — строка). В модуле 2 такую таблицу будет хранить `pandas.DataFrame`, а подсчёт по категориям сделает одна функция `value_counts`.

## Типичные ошибки

:::mistake Нумерация с единицы
`prices[1]` — это **второй** элемент. Первый — `prices[0]`, последний — `prices[-1]`.
:::

:::mistake Индекс за границей
`prices[len(prices)]` вызывает `IndexError: list index out of range`: последний номер на единицу меньше длины.
:::

:::mistake Ключа нет в словаре
`car['Price']` при ключе `'price'` → `KeyError`. Ключи чувствительны к регистру; для необязательных — `.get()`.
:::

## Что запомнить

- Список — значения по порядку; номера с нуля, `-1` — последний, `len()` — длина, срез `a[i:j]` без `j`.
- `.append(x)` добавляет, `x in lst` проверяет наличие, `.index(x)` — позиция значения.
- Словарь — пары ключ: значение; `d[key]`, `d.get(key, default)`, `d.items()`.
- `*` и `+` у списков — повторение и склейка, а не арифметика.
